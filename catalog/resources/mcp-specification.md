# Model Context Protocol specification

`res:mcp-specification` - standard - <https://modelcontextprotocol.io/specification/2025-06-18>

**By:** Model Context Protocol project - **Year:** 2025 - **Level:** intermediate - **Access:** open

The specification for MCP, the protocol LLM clients use to call tools and read resources from servers; the basis of the ROS, MAVLink and QGIS MCP servers.

## Key takeaways

- Tools, resources and prompts as server primitives
- Transport and authorization rules
