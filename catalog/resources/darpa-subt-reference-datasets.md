# DARPA SubT Reference Datasets

`res:darpa-subt-reference-datasets` - dataset - <https://bitbucket.org/subtchallenge/subt_reference_datasets>

**By:** DARPA Subterranean Challenge - **Year:** 2019 - **Level:** advanced - **Access:** open

Reference sensor datasets and artifact data released for the DARPA Subterranean Challenge, hosted on Bitbucket.

## Key takeaways

- Sensors: lidar, cameras, IMU from SubT-style robots
- GNSS-denied underground
- Tunnel and Urban circuit bags only, collected by the Army Research Laboratory
- No licence stated in the repo or data bucket
