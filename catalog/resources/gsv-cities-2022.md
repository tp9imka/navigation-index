# GSV-Cities: Toward Appropriate Supervised Visual Place Recognition

`res:gsv-cities-2022` - dataset - <https://arxiv.org/abs/2210.10239>

**By:** Amar Ali-bey, Brahim Chaib-draa, Philippe Giguere - **Year:** 2022 - **Level:** intermediate - **Access:** open

Neurocomputing 2022 paper introducing GSV-Cities, a street-level training set covering 40+ cities over 14 years with accurate place labels, and a study of metric-learning losses for VPR training. It is the training set used by MixVPR, BoQ and several later methods. Licence: the Kaggle dataset is CC BY-NC-ND 4.0 (non-commercial, no derivatives); the GitHub code repo has no licence file.

## Key takeaways

- Standard training set for modern VPR
- CC BY-NC-ND 4.0: research use only
