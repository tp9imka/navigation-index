# Navigating Using GPS Localization (Nav2 tutorial)

`res:nav2-gps-navigation-tutorial` - doc - <https://docs.nav2.org/rolling/tutorials/general_tutorials/navigation2_with_gps/navigation2_with_gps/>

**By:** Open Navigation, Nav2 contributors - **Year:** 2024 - **Level:** intermediate - **Access:** open

Nav2 tutorial on outdoor navigation with GPS: fusing GNSS, IMU and odometry with robot_localization's navsat_transform, configuring Nav2 for GPS waypoints, and demonstrating it in Gazebo.

## Key takeaways

- Shortest working path to GPS waypoint following on a ROS 2 robot
- Shows datum and frame setup that trips people up
