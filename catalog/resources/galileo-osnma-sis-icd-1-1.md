# Galileo OSNMA Signal-In-Space ICD v1.1

`res:galileo-osnma-sis-icd-1-1` - standard - <https://www.gsc-europa.eu/sites/default/files/sites/all/files/Galileo_OSNMA_SIS_ICD_v1.1.pdf>

**By:** European Union / EUSPA - **Year:** 2023 - **Level:** advanced - **Access:** open

Specifies Galileo Open Service Navigation Message Authentication: the TESLA-based key chain, MAC and key messages carried in I/NAV, and the public key/Merkle tree structure.

## Key takeaways

- Civil signal authentication is available today on Galileo E1-B
- Receivers need loose time synchronization to verify TESLA keys
- Defines what an authenticated vs unauthenticated navigation message means
