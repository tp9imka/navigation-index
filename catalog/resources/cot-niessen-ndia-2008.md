# Cursor on Target (NDIA briefing)

`res:cot-niessen-ndia-2008` - talk - <https://ndia.dtic.mil/wp-content/uploads/2008/USCG/Wednesday/2NiessenCursorOnTarget.pdf>

**By:** MITRE (Niessen) - **Year:** 2008 - **Level:** intro - **Access:** open

Briefing introducing the Cursor on Target XML event schema: the minimal event/point/detail model for exchanging what-when-where of tracked entities between C2 systems.

## Key takeaways

- Base schema is tiny: event, point, detail
- Type strings follow a hierarchical a-f-G-... code derived from symbology
- Extensibility lives in the detail element
