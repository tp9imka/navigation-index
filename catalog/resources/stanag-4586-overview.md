# STANAG 4586 - Standard Interfaces of UAV Control System (UCS) for NATO UAV Interoperability

`res:stanag-4586-overview` - doc - <https://en.wikipedia.org/wiki/STANAG_4586>

**By:** NATO (summary: Wikipedia) - **Year:** 2017 - **Level:** intro - **Access:** open

Public overview of NATO's UAS interoperability standard, which defines a core UCS, a vehicle-specific module and five levels of interoperability from receiving payload data up to full flight control including launch and recovery.

## Key takeaways

- LOI 1-3 cover payload data and control; LOI 4-5 cover flight control
- Vehicle Specific Module isolates proprietary air vehicle interfaces
- Full text distributed via NATO / national channels
