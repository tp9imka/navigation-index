# RFC 7384: Security Requirements of Time Protocols in Packet Switched Networks

`res:rfc7384-time-protocol-security` - standard - <https://www.rfc-editor.org/rfc/rfc7384>

**By:** T. Mizrahi - **Year:** 2014 - **Level:** intermediate - **Access:** open

Threat model and security requirements for NTP and PTP: packet manipulation, spoofing, replay, rogue master, delay attacks, cryptographic attacks and DoS.

## Key takeaways

- Delay attacks cannot be stopped by cryptography alone
- Useful checklist for a timing threat model slide
