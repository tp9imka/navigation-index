# NMEA Revealed (gpsd project)

`res:gpsd-nmea-revealed` - doc - <https://gpsd.gitlab.io/gpsd/NMEA.html>

**By:** Eric S. Raymond / gpsd project - **Year:** 2024 - **Level:** intro - **Access:** open

A free, detailed field-by-field reference to NMEA 0183 sentences as actually emitted by real receivers, including vendor quirks and version differences. The practical substitute for the paywalled standard.

## Key takeaways

- Documents real-world deviations from the standard
- Covers talker IDs for multi-GNSS output
- Written by gpsd maintainers who parse these daily
