# Optimal Trajectory Generation for Improved Magnetic Navigation

`res:kang-2026-optimal-trajectory-magnetic-navigation` - paper - <https://arxiv.org/abs/2609.27553>

**By:** Justin Kang, Teddy Herrera, Liraz Mudrik, Sean Kragelund, Alfonso Sciacchitano, Isaac Kaminer - **Year:** 2026 - **Level:** advanced - **Access:** open

arXiv preprint. Formulates magnetic-anomaly navigation trajectory design as an optimal control problem that minimises the posterior Cramer-Rao bound on position error with a path-length penalty; optimized paths beat straight lines in simulation. Abstract only read; vehicle constraints and code not stated there.

## Key takeaways

- Map-referenced trajectory design by an information bound, very recent
- A CRB is local: it does not address several separated hypotheses
