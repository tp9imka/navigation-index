# Required Navigation Performances for Drone Flight Operations

`res:haro-2023-rnp-drone-operations` - paper - <https://www.mdpi.com/2673-4591/54/1/51>

**By:** Pablo Haro, C. Aguilera, G. Lucchi - **Year:** 2023 - **Level:** intermediate - **Access:** open

Conference paper (Engineering Proceedings 54(1):51, 2023). Proposes RNP specifications for drones from the error sources that make up total system error: path definition, flyability, autopilot envelope, positioning error and environment. Read as abstract only.

## Key takeaways

- Aviation already sizes containment from TSE = path definition + flight technical + navigation system error
- Containment is a planning and approval margin, not a live safety filter
