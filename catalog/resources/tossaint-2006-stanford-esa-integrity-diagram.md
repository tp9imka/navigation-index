# The Stanford - ESA Integrity Diagram: Focusing on SBAS Integrity

`res:tossaint-2006-stanford-esa-integrity-diagram` - paper - <https://upcommons.upc.edu/entities/publication/6bcb2d3c-733c-43ee-9ce8-03bd62cdc56e>

**By:** Michel Tossaint, Jaron Samson, Felix Toran, Javier Ventura-Traveset, Jaume Sanz, Manuel Hernandez-Pajares, Jose Miguel Juan - **Year:** 2006 - **Level:** intermediate - **Access:** open

ION GNSS 2006 paper (UPC UPCommons repository record, behind a bot check) that modifies the classical Stanford plot to focus strictly on integrity, since the classical plot is not always conservative for that purpose. Also proposes an 'all-geometries' diagram and reports EGNOS measurement results under this stricter test. The Stanford-ESA diagram became a main integrity assessment tool for EGNOS.

## Key takeaways

- Stanford-ESA variant is the integrity-conservative version of the Stanford plot
- Used for EGNOS safety assessment
- Good template for plotting alt-PNT protection levels
