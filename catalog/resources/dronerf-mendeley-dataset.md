# DroneRF dataset: A dataset of drones for RF-based detection, classification, and identification

`res:dronerf-mendeley-dataset` - dataset - <https://data.mendeley.com/datasets/f4c2b4n755/1>

**By:** Mohammad Al-Sa'd, Mhd Saria Allahham, Amr Mohamed, Abdulla Al-Ali, Tamer Khattab, Aiman Erbad - **Year:** 2019 - **Level:** intermediate - **Access:** open

RF recordings of drone-to-controller communications from three consumer drones (Bebop, AR Drone, Phantom) in several flight modes, plus background recordings with no drone, collected at Qatar University. Published on Mendeley Data under CC BY 4.0 as segmented RAR archives of CSV sample text.

## Key takeaways

- Classic baseline for RF-based drone detection and type identification
- Archives expand a lot: the cuas-classifiers sample's 4-archive subset is about 0.7 GB packed and 6.6 GB of CSV
- Mendeley's API rejects the default urllib user agent; set one explicitly
- Detection and classification only; the sample rate is not stated in the dataset description
