# ITU-R M.1371 - Technical characteristics for an automatic identification system using TDMA in the VHF maritime mobile band

`res:itu-r-m1371-ais` - standard - <https://www.itu.int/rec/R-REC-M.1371>

**By:** ITU-R - **Year:** 2014 - **Level:** advanced - **Access:** open

The ITU recommendation defining AIS radio, TDMA access and message formats that decoders such as pyais implement.

## Key takeaways

- Defines message types 1-27 decoded by pyais and AIS-catcher
- AIS is unauthenticated, so spoofing detection is an open problem
