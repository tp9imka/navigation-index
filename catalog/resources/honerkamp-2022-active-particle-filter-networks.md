# Active Particle Filter Networks: Efficient Active Localization in Continuous Action Spaces and Large Maps

`res:honerkamp-2022-active-particle-filter-networks` - paper - <https://arxiv.org/abs/2209.09646>

**By:** Daniel Honerkamp, Suresh Guttikonda, Abhinav Valada - **Year:** 2022 - **Level:** advanced - **Access:** open

arXiv preprint. Couples a differentiable particle filter with an RL agent acting in continuous action spaces, using only local map information so cost does not grow with the global map. Indoor 3D-scanned apartments. Abstract only read.

## Key takeaways

- Particle belief + continuous actions + large maps
- Indoor ground robot, no aircraft limits
