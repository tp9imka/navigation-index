# Predictive and Self Triggering for Event-based State Estimation

`res:trimpe-2016-predictive-self-triggering-estimation` - paper - <https://arxiv.org/abs/1609.07534>

**By:** Sebastian Trimpe - **Year:** 2016 - **Level:** advanced - **Access:** open

CDC 2016 paper (doi 10.1109/CDC.2016.7798733; arXiv 1609.07534). Self-triggers predict the next triggering instant at the current one; predictive triggers say whether a transmission will be needed within a horizon, so the shared resource can be re-allocated ahead of time. Both come from one Bayesian decision framework. Abstract only read.

## Key takeaways

- Self-trigger = predict the next update time now, the 'deadline' idea for a network
- Predictive trigger lets the resource be booked in advance
- Assumes measurements always arrive; no compute latency
