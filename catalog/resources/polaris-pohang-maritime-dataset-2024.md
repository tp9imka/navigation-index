# PoLaRIS Dataset: A Maritime Object Detection and Tracking Dataset in Pohang Canal

`res:polaris-pohang-maritime-dataset-2024` - dataset - <https://arxiv.org/abs/2412.06192>

**By:** Jiwon Choi, Dongjin Cho, Gihyeon Lee, Hogyun Kim, Geonmo Yang, Joowan Kim, Younggun Cho - **Year:** 2024 - **Level:** intermediate - **Access:** open

Inha University dataset that adds object detection and tracking labels to five Pohang Canal sequences, with annotations on RGB, thermal, LiDAR and radar data for objects as small as 10x10 pixels. No separate licence stated; the underlying Pohang Canal data is CC BY-NC 4.0 (non-commercial).

## Key takeaways

- Adds object labels to the Pohang Canal setting
- Multi-modal labels for camera, thermal, LiDAR and radar detection on USVs
- Inherits the non-commercial terms of the Pohang Canal data
