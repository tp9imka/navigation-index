# PoLaRIS Dataset: A Maritime Object Detection and Tracking Dataset in Pohang Canal

`res:polaris-pohang-maritime-dataset-2024` - dataset - <https://arxiv.org/abs/2412.06192>

**By:** KAIST - **Year:** 2024 - **Level:** intermediate - **Access:** open

Maritime object detection and tracking dataset recorded in Pohang Canal with image and point-wise annotations of hazards.

## Key takeaways

- Adds object labels to the Pohang Canal setting
- Supports camera and LiDAR detection for USVs
