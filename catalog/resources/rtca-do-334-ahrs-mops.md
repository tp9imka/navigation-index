# RTCA DO-334: Minimum Operational Performance Standards (MOPS) for Strapdown Attitude and Heading Reference Systems (AHRS)

`res:rtca-do-334-ahrs-mops` - standard - <https://standards.globalspec.com/std/1538865/rtca-do-334>

**By:** RTCA - **Year:** 2012 - **Level:** advanced - **Access:** paywalled

Performance standard for strapdown AHRS equipment that outputs attitude and heading. Catalogue listings date it 2012-03-21; DO-384 builds on it. Closest RTCA MOPS to an inertial-only nav fallback on a small aircraft. Only the catalogue summary was read, not the standard.

## Key takeaways

- Specifies equipment characteristics, not output data formats
- Sets the performance baseline an IMU-based fallback would be compared against
- DO-229 (SBAS) and DO-316 (GPS/ABAS) are the GNSS-side MOPS; this is the inertial-side one
