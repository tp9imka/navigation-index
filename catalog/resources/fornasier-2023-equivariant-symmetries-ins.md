# Equivariant Symmetries for Inertial Navigation Systems

`res:fornasier-2023-equivariant-symmetries-ins` - paper - <https://arxiv.org/abs/2309.03765>

**By:** Alessandro Fornasier, Yixiao Ge, Pieter van Goor, Robert Mahony, Stephan Weiss - **Year:** 2023 - **Level:** advanced - **Access:** open

Shows that the modern EKF variants for inertial navigation, including the invariant EKF, are equivariant filters with different symmetry groups, and derives GNSS-aided versions for each. The reference for choosing a symmetry for an INS filter.

## Key takeaways

- Preprint; repo description calls it an Automatica submission
- Compares IEKF, TG-EqF and other EqFs on error and consistency
- MATLAB code exists but has no license file
