# Perception-aware trajectory generation for aggressive quadrotor flight using differential flatness

`res:murali-perception-aware-yaw-acc2019` - paper - <https://dspace.mit.edu/handle/1721.1/132953>

**By:** Varun Murali, Igor Spasojevic, Winter J. Guerra, Sertac Karaman - **Year:** 2019 - **Level:** advanced - **Access:** open

Chooses a yaw trajectory that keeps tracked features co-visible while the position trajectory stays aggressive, using differential flatness. Reports almost 70% lower tracking RMSE thanks to better state estimation. ACC 2019.

## Key takeaways

- Yaw-only perception awareness is cheap and strong
- The baseline any 48h perception-aware entry must beat
