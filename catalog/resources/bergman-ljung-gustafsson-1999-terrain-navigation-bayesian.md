# Terrain navigation using Bayesian statistics

`res:bergman-ljung-gustafsson-1999-terrain-navigation-bayesian` - paper - <https://doi.org/10.1109/37.768538>

**By:** Niclas Bergman, Lennart Ljung, Fredrik Gustafsson - **Year:** 1999 - **Level:** intermediate - **Access:** paywalled

IEEE Control Systems Magazine 19(3) article presenting the point-mass filter for terrain-aided aircraft navigation: a grid approximation of the position density propagated recursively. Monte Carlo and realistic simulations show near-optimal performance across terrain types; the main limit is that cost explodes with state dimension. An open copy is in Linkoping's DiVA.

## Key takeaways

- The PMF handles arbitrary nonlinearity and noise in low dimension
- Density shape tells you estimate quality
- Real time for 2D, sometimes 3D
