# UTIL: UWB TDoA dataset

`res:util-uwb-dataset` - dataset - <https://utiasdsl.github.io/util-uwb-dataset/>

**By:** University of Toronto Dynamic Systems Lab - **Year:** 2022 - **Level:** intermediate - **Access:** open

Project page for a UWB TDoA dataset collected with Loco Positioning hardware, with ground truth for evaluating indoor UWB localization.

## Key takeaways

- Real UWB data including non-line-of-sight effects
- Useful to benchmark estimators before buying hardware
