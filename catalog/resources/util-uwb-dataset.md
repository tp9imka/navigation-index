# UTIL: An Ultra-wideband Time-difference-of-arrival Indoor Localization Dataset

`res:util-uwb-dataset` - dataset - <https://learnsyslab.github.io/util-uwb-dataset/>

**By:** Wenda Zhao, Abhishek Goudar, Xinyuan Qiao, Angela P. Schoellig - **Year:** 2022 - **Level:** intermediate - **Access:** open

Project page for a UWB TDoA dataset collected with Loco Positioning hardware, with ground truth for evaluating indoor UWB localization. No licence file in the learnsyslab/util-uwb-dataset GitHub repo, so reuse terms are unstated (all rights reserved by default).

## Key takeaways

- Real UWB data including non-line-of-sight effects
- Useful to benchmark estimators before buying hardware
