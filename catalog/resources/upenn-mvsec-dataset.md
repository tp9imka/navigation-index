# The Multi Vehicle Stereo Event Camera Dataset (MVSEC)

`res:upenn-mvsec-dataset` - dataset - <https://daniilidis-group.github.io/mvsec/>

**By:** University of Pennsylvania - **Year:** 2018 - **Level:** advanced - **Access:** open

Stereo event cameras with IMU, lidar and ground truth on several platforms including a hexacopter and a car.

## Key takeaways

- Sensors: stereo event, IMU, lidar, GPS
- Platforms: drone, car, motorcycle, handheld
