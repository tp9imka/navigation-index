# TartanAir: A Dataset to Push the Limits of Visual SLAM

`res:cmu-tartanair-dataset` - dataset - <https://theairlab.org/tartanair-dataset/>

**By:** CMU AirLab - **Year:** 2020 - **Level:** intermediate - **Access:** open

Large synthetic dataset rendered in AirSim/Unreal environments with challenging lighting, weather and motion, with perfect ground truth for many modalities.

## Key takeaways

- Sensors (simulated): stereo, depth, segmentation, flow, lidar (no IMU in v1)
- Size class: very large
- Licence: CC BY 4.0
