# EU-U.S. Cooperation on Satellite Navigation, Working Group C-ARAIM Technical Subgroup - Milestone 2 Report

`res:wgc-araim-milestone-2-report-2015` - report - <https://archive.gps.gov/policy/cooperation/europe/2015/working-group-c/ARAIM-milestone-2-report.pdf>

**By:** EU-U.S. Cooperation on Satellite Navigation, Working Group C - ARAIM Technical Subgroup - **Year:** 2015 - **Level:** advanced - **Access:** open

Final version dated 11 February 2015. Describes the candidate ARAIM architectures (Horizontal ARAIM and Offline and Online Vertical ARAIM), the Integrity Support Message (ISM) concept that lets a ground system update constellation fault rates and error models, threat allocation, and extended availability results, for comment by the aviation community.

## Key takeaways

- Horizontal vs offline vs online vertical ARAIM
- ISM: ground-provided integrity parameters without avionics changes
- Wider URE/SISE and constellation scenarios
