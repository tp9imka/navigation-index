# UWB-based system for UAV Localization in GNSS-Denied Environments: Characterization and Dataset

`res:tiers-uwb-uav-dataset-2020` - dataset - <https://arxiv.org/abs/2003.04380>

**By:** Jorge Pena Queralta, Carmen Martinez Almansa, Fabrizio Schiano, Dario Floreano, Tomi Westerlund - **Year:** 2020 - **Level:** intermediate - **Access:** open

IROS 2020 paper characterizing a low-cost, portable Decawave DWM1001 UWB system for indoor UAV flight, including anchor placement, altitude and speed effects and anchor self-calibration, with open data and methods. Data in the TIERS/uwb-drone-dataset GitHub repo, which has no licence file.

## Key takeaways

- Cheap DWM1001 hardware, movable anchors
- Accuracy vs anchor geometry and altitude
- No explicit licence
