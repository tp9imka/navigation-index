# Jammertest - open GNSS jamming and spoofing test event (Andoya, Norway)

`res:jammertest-norway` - competition - <https://jammertest.no/>

**By:** Norwegian Communications Authority, FFI, NPRA and partners, Norwegian public authorities (NPRA, Nkom, FFI and others) - **Year:** 2025 - **Level:** intermediate - **Access:** open

Annual open field event where Norwegian agencies transmit real jamming, spoofing and meaconing so vendors and researchers can test PNT equipment. The public test catalogue and community datasets make it the best source of real interference recordings.

## Key takeaways

- Real over-the-air jamming and spoofing in a controlled area
- Published test catalogue and plan
- Participants release datasets on GitHub
- Real jamming/spoofing scenarios documented in the public test plan
- Use the catalog to design realistic sim scenarios
