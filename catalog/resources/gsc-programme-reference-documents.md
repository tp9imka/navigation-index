# European GNSS Service Centre - Programme Reference Documents

`res:gsc-programme-reference-documents` - doc - <https://www.gsc-europa.eu/electronic-library/programme-reference-documents>

**By:** European GNSS Service Centre - **Year:** 2025 - **Level:** intro - **Access:** open

Library of current Galileo ICDs, service definition documents and receiver guidelines (OS, HAS, OSNMA, SAR). Check here for the latest issue numbers before implementing.

## Key takeaways

- Authoritative versions of all public Galileo specs
- Includes service definition documents with committed performance
- Includes the HAS (High Accuracy Service) ICD for free PPP corrections
