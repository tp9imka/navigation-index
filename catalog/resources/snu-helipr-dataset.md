# HeLiPR: Heterogeneous LiDAR Dataset for inter-LiDAR Place Recognition

`res:snu-helipr-dataset` - dataset - <https://sites.google.com/view/heliprdataset>

**By:** SNU RPM Robotics Lab - **Year:** 2024 - **Level:** advanced - **Access:** free-registration

Same routes captured with Ouster, Aeva, Livox and Velodyne lidars to test place recognition across different lidar types.

## Key takeaways

- Sensors: four lidar types, IMU, GNSS/INS
- Use for cross-sensor relocalization
- Licence: CC BY-NC-SA 4.0, non-commercial; download via request form
