# SubPipe: A Submarine Pipeline Inspection Dataset for Segmentation and Visual-inertial Localization

`res:subpipe-paper-2024` - paper - <https://arxiv.org/abs/2401.17907>

**By:** Olaya Alvarez-Tunon, Luiza Ribeiro Marnet, Laszlo Antal, Martin Aubard, Maria Costa, Yury Brodskiy - **Year:** 2024 - **Level:** intermediate - **Access:** open

Describes an AUV dataset from a real pipeline inspection mission (OceanScan LAUV) with two cameras, side-scan sonar and navigation data, with SLAM, RGB segmentation and sonar object detection baselines. Data on Zenodo under CC BY 4.0 with a required copyright notice.

## Key takeaways

- Open underwater visual SLAM benchmark with pose ground truth from navigation sensors
- Side-scan sonar object detection labels (COCO and YOLO); segmentation labels are on RGB
