# IS-GPS-705J: NAVSTAR GPS Space Segment / User Segment L5 Interfaces

`res:gps-is-gps-705j` - standard - <https://archive.gps.gov/technical/icwg/IS-GPS-705J.pdf>

**By:** US Space Force / GPS ICWG - **Year:** 2022 - **Level:** advanced - **Access:** open

Interface specification for the GPS L5 safety-of-life band signal: I5/Q5 codes, the L5 CNAV message, and signal characteristics. L5's higher chipping rate and wider band make it more robust to narrowband interference than L1 C/A.

## Key takeaways

- Defines the L5 dataless pilot (Q5) and data (I5) channels
- CNAV message types shared with L2C
- Draft uprevisions were discussed at the 2025 public ICWG
