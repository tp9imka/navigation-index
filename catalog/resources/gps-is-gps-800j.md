# IS-GPS-800J: NAVSTAR GPS Space Segment / User Segment L1C Interfaces

`res:gps-is-gps-800j` - standard - <https://archive.gps.gov/technical/icwg/IS-GPS-800J.pdf>

**By:** US Space Force / GPS ICWG - **Year:** 2022 - **Level:** advanced - **Access:** open

Interface specification for the modernized L1C civil signal designed for interoperability with Galileo E1 and other GNSS: BOC/TMBOC modulation, Weil-code ranging codes, and the CNAV-2 message.

## Key takeaways

- L1C uses a pilot plus data component, like Galileo E1
- CNAV-2 adds FEC-coded subframes
- Key reference for multi-GNSS L1 receiver design
