# Neural-Fly enables rapid learning for agile flight in strong winds

`res:oconnell-2022-neural-fly` - paper - <https://www.science.org/doi/abs/10.1126/scirobotics.abm6597>

**By:** Michael O'Connell, Guanya Shi, Xichen Shi, Kamyar Azizzadenesheli, Anima Anandkumar, Yisong Yue, Soon-Jo Chung - **Year:** 2022 - **Level:** advanced - **Access:** paywalled

Science Robotics 7 (2022). Learns a wind-invariant basis for the quadrotor aerodynamic residual offline, then adapts a small linear layer online; released flight data covers fan-array winds up to several m/s.

## Key takeaways

- Aerodynamic residual is learnable and adaptable in flight
- Released data has PWM and thrust setpoints at labelled wind speeds
- Data and code are personal/educational use only
