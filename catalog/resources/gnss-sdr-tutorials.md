# GNSS-SDR tutorials

`res:gnss-sdr-tutorials` - doc - <https://gnss-sdr.org/docs/tutorials/>

**By:** GNSS-SDR project (CTTC) - **Year:** 2024 - **Level:** intermediate - **Access:** open

Tutorials for the open-source GNSS-SDR software receiver: GNSS open-service signals, running with a low-cost RTL2832U DVB-T dongle as front end, monitoring the receiver's internal status, build-time options, cross-compiling for embedded platforms, data types and the testing framework. Acquisition, tracking and PVT blocks are documented in the site's Signal Processing Blocks section.

## Key takeaways

- Learn receiver internals with real IQ data
- Base for interference-detection experiments
