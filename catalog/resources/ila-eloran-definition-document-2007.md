# Enhanced Loran (eLoran) Definition Document

`res:ila-eloran-definition-document-2007` - doc - <https://rntfnd.org/wp-content/uploads/eLoran-Definition-Document-0-1-Released.pdf>

**By:** International Loran Association - **Year:** 2007 - **Level:** intermediate - **Access:** open

High-level definition of eLoran for policy makers, service providers and users: what distinguishes it from Loran-C (UTC-synchronised transmitters, a data channel, differential corrections) and the positioning and timing services it is meant to provide. The linked copy is version 0.1 issued for consultation in January 2007.

## Key takeaways

- eLoran transmissions are tied to UTC, which is what makes it a GNSS-independent timing source
- Draft for consultation - check later ILA material before quoting requirement numbers
