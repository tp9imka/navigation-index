# KITTI Visual Odometry / SLAM Evaluation

`res:kitti-odometry-benchmark` - dataset - <https://www.cvlibs.net/datasets/kitti/eval_odometry.php>

**By:** KIT, Toyota Technological Institute - **Year:** 2012 - **Level:** intro - **Access:** free-registration

Driving sequences with stereo cameras, Velodyne lidar and GPS/IMU ground truth, plus a public leaderboard for odometry.

## Key takeaways

- Sensors: stereo, lidar, GPS/IMU
- Size class: large
- License: CC BY-NC-SA per site
- Registration required; leaderboard accepts only novel work aimed at a peer-reviewed paper
