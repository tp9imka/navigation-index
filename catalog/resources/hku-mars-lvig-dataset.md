# MARS-LVIG Dataset: A multi-sensor aerial robots SLAM dataset for LiDAR-visual-inertial-GNSS fusion

`res:hku-mars-lvig-dataset` - dataset - <https://mars.hku.hk/dataset.html>

**By:** HKU MaRS Lab - **Year:** 2024 - **Level:** advanced - **Access:** open

Aerial robot SLAM dataset for lidar-visual-inertial-GNSS fusion, including sequences with raw GNSS measurements under different lighting.

## Key takeaways

- Sensors: lidar, camera, IMU, GNSS (incl. raw)
- Domain: aerial over large outdoor areas
- Licence: CC BY-NC-SA 4.0, academic use only
