# A Novel Adaptive Kalman Filter With Inaccurate Process and Measurement Noise Covariance Matrices

**By:** Yulong Huang, Yonggang Zhang, Zhemin Wu, Ning Li - **Year:** 2018 - **Level:** advanced - **Access:** paywalled

IEEE Transactions on Automatic Control 2018. Variational Bayes adaptive Kalman filter that treats both the predicted covariance and the measurement noise covariance as uncertain (inverse-Wishart). Widely used base for GNSS/INS adaptive filters.
