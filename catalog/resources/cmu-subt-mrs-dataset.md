# SubT-MRS Dataset

`res:cmu-subt-mrs-dataset` - dataset - <https://superodometry.com/datasets>

**By:** CMU AirLab - **Year:** 2024 - **Level:** advanced - **Access:** open

Multi-robot, multi-modal SLAM data in degraded environments - caves, tunnels, urban and off-road - with RGB, lidar, thermal and inertial sensing; used in ICCV SLAM challenges.

## Key takeaways

- Sensors: RGB, lidar, thermal, IMU
- Domains: subterranean, off-road
- Size class: large
- No licence stated on the dataset page
