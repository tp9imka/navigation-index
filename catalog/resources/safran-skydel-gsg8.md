# Safran Skydel simulation engine / GSG-8 GNSS simulator (ex-Orolia)

`res:safran-skydel-gsg8` - product - <https://www.safran-group.com/products-services/skydel-gsg-8-advanced-gnss-simulator>

**By:** Safran (ex-Orolia) - **Year:** 2024 - **Level:** intermediate - **Access:** open

Skydel is the SDR/GPU-based simulation engine behind Safran's GSG-8 simulators, with built-in jamming and spoofing scenarios, CRPA wavefront variants and LEO PNT signal options; Safran offers it to universities through an academic programme.

## Key takeaways

- Vendor datasheet: jamming and spoofing generated without extra hardware
- Spoofing workflows run a 'truth' and a 'spoofer' instance - a useful mental model for test design
