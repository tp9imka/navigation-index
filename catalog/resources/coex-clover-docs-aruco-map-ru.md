English: 'Navigation by marker map - Clover docs'. Russian documentation for flying with a map of ArUco markers (floor or ceiling), publishing the resulting pose to the flight controller as a vision position estimate, and commanding flights in the marker-map frame. Year approximate.

## Key takeaways

- Fiducial maps are the fastest way to get GNSS-free indoor positioning for a demo
- Shows the generic pattern: external pose => VPE => autopilot EKF
