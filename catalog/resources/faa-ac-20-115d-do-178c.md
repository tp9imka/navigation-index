# FAA AC 20-115D: Airborne Software Development Assurance Using EUROCAE ED-12( ) and RTCA DO-178( )

`res:faa-ac-20-115d-do-178c` - standard - <https://www.faa.gov/documentLibrary/media/Advisory_Circular/AC_20-115D.pdf>

**By:** FAA - **Year:** 2017 - **Level:** intermediate - **Access:** open

The FAA advisory circular that recognises RTCA DO-178C / EUROCAE ED-12C as an acceptable means to show airborne software meets airworthiness rules. EASA's AMC 20-115D is the technically equivalent European text. DO-178C itself is paywalled; this AC is the free entry point.

## Key takeaways

- DO-178C assigns a software level (A-E) from the failure condition the software can cause
- Level drives the number of objectives and independence, not the coding language
- Advisory, not mandatory, but the default path regulators expect
- AMC 20-115D (EASA) and AC 20-115D (FAA) are technically identical
