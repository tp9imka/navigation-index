# Low-cost GPS simulator: GPS spoofing by SDR (DEF CON 23)

`res:defcon23-low-cost-gps-spoofing-sdr` - talk - <https://infocondb.org/con/def-con/def-con-23/low-cost-gps-simulator-gps-spoofing-by-sdr>

**By:** Lin Huang, Qing Yang, Qihoo 360 Unicorn Team - **Year:** 2015 - **Level:** intermediate - **Access:** open

DEF CON 23 talk showing that open-source tools and cheap SDRs can generate counterfeit GPS L1 signals that fool phones and a consumer drone; the speakers end with defensive advice such as multi-constellation positioning and spoofing detection in chipsets.

## Key takeaways

- Shows how low the barrier to civil GPS spoofing is
- Motivates detection and multi-source fusion in any drone build
