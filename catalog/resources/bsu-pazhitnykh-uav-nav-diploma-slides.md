# Разработка алгоритмов навигации БПЛА

`res:bsu-pazhitnykh-uav-nav-diploma-slides` - report - <https://drapegnik.github.io/bsu-science/diploma/presentation.pdf>

**By:** I. Pazhitnykh, O. M. Kondratieva (supervisor), BSU FAMCS - **Year:** 2018 - **Level:** intro - **Access:** open

English: 'Development of UAV navigation algorithms'. Diploma defence slides from Belarusian State University: goal is to use the drone camera for positioning without GPS; compares SIFT, SURF and ORB, reviews SLAM and SfM 3D terrain mapping, and demonstrates SLAM + ROS + webcam + SfM localisation on a 3D map.

## Key takeaways

- Student-level overview of feature choice and SLAM/SfM for GPS-free localisation
- Slides only
