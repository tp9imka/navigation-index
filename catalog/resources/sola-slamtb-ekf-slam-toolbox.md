# SLAM toolbox for Matlab (EKF-SLAM teaching code)

`res:sola-slamtb-ekf-slam-toolbox` - course - <https://github.com/joansola/slamtb>

**By:** Joan Solà - **Year:** 2013 - **Level:** intermediate - **Access:** open

Solà's Matlab EKF-SLAM toolbox, used as teaching material for his SLAM courses: modular robots, sensors, landmark parameterizations (including inverse-depth points and lines) and graph-SLAM variants. Old but clear code for learning.

## Key takeaways

- Readable reference implementation of EKF-SLAM
- Shows landmark parameterization trade-offs
