# Flow deck v2

`res:bitcraze-flow-deck-v2` - doc - <https://www.bitcraze.io/products/flow-deck-v2/>

**By:** Bitcraze - **Year:** 2026 - **Level:** intro - **Access:** open

Crazyflie deck combining a PMW3901 optical flow sensor and a VL53L1x height sensor, fused in the onboard EKF for indoor position hold without external infrastructure.

## Key takeaways

- Height up to about 4 m
- Works best on matte, textured floors
- Drift grows with distance flown
