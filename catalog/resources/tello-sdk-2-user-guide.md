# Tello SDK 2.0 User Guide

`res:tello-sdk-2-user-guide` - doc - <https://dl-cdn.ryzerobotics.com/downloads/Tello/Tello%20SDK%202.0%20User%20Guide.pdf>

**By:** Ryze Robotics / DJI - **Year:** 2018 - **Level:** intro - **Access:** open

The UDP text command set for Tello EDU: control, set and read commands, mission pad commands and state stream format.

## Key takeaways

- go x y z speed in cm, +-500, 10-100 cm/s
- rc a b c d gives stick-level control without ack
- Auto-land after 15 s without a command
