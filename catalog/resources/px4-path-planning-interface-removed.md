# Path Planning Interface (PX4 User Guide, marked removed)

`res:px4-path-planning-interface-removed` - doc - <https://docs.px4.io/main/en/computer_vision/path_planning_interface>

**By:** PX4 / Dronecode - **Year:** 2026 - **Level:** intro - **Access:** open

Docs. The page for the old companion-computer obstacle avoidance interface (PX4-Avoidance, COM_OBS_AVOID). The main branch marks it removed; the v1.16 page says it is unsupported and should not be used in any version.

## Key takeaways

- PX4 no longer ships an onboard path-planning hook for avoidance
- Companion planners now drive PX4 through Offboard or ROS 2 external modes
- PX4-Avoidance repo is archived
