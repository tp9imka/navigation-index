# Learning Where to Look: Self-supervised Viewpoint Selection for Active Localization using Geometrical Information

`res:di-giammarino-2024-learning-where-to-look` - paper - <https://arxiv.org/abs/2407.15593>

**By:** Luca Di Giammarino, Boyang Sun, Giorgio Grisetti, Marc Pollefeys, Hermann Blum, Daniel Barath - **Year:** 2024 - **Level:** advanced - **Access:** open

ECCV 2024 (per the repository README). Learns from a Structure-from-Motion model which camera orientation gives the best visual localization at a location, and uses it inside a planner. Abstract and README read.

## Key takeaways

- Look-direction choice for accuracy of one estimate, not hypothesis separation
