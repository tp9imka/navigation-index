# Addressing Relative Pose Impact on UWB Localization: Dataset Introduction and Analysis

`res:rcv-uwb-relative-pose-dataset-2024` - dataset - <https://arxiv.org/abs/2407.03890>

**By:** Jun Hyeok Choe, Inwook Shim - **Year:** 2024 - **Level:** intermediate - **Access:** open

Short paper introducing a drone UWB dataset that isolates how the relative pose between UWB devices affects ranging: six flight sequences with two-way ranging to four anchors, a stereo VIO setup, and motion-capture ground truth for both the drone and the anchors. Data in the cjhhalla/RCV_uwb_dataset GitHub repo (rosbags on Google Drive), which has no licence file, so reuse terms are unstated.

## Key takeaways

- Characterizes antenna-orientation effects on UWB range error
- Useful for building a realistic UWB noise model
- No explicit licence
