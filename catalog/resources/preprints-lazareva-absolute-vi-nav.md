# Разработка алгоритма абсолютной визуально-инерциальной навигации беспилотных воздушных судов

`res:preprints-lazareva-absolute-vi-nav` - paper - <https://preprints.ru/files/2118>

**By:** P. A. Lazareva, A. I. Malikov, G. L. Degtyarev, R. T. Mannanov - **Year:** 2025 - **Level:** advanced - **Access:** open

English: 'Development of an absolute visual-inertial navigation algorithm for unmanned aircraft'. Russian preprint comparing absolute navigation methods against preloaded satellite maps and proposing a season-invariant SIFT keypoint matching approach corrected by INS, optimised for real time and evaluated on real flight data against GNSS reference. Year inferred from the PDF (references run to 2025).

## Key takeaways

- Absolute map-based fixes + INS is the mainstream Russian approach too
- Seasonal invariance is the named key problem
- Evaluated against GNSS reference on real flights
