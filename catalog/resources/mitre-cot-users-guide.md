# Cursor-on-Target Message Router User's Guide

`res:mitre-cot-users-guide` - doc - <https://www.mitre.org/sites/default/files/pdf/09_4937.pdf>

**By:** Michael J. Kristan, Jeffrey T. Hamalainen, Douglas P. Robbins, Patrick J. Newell (MITRE) - **Year:** 2009 - **Level:** intro - **Access:** open

MITRE guide describing Cursor-on-Target: the base Event schema (what, where, when), its mandatory fields, sub-schema extensions and the message router used to distribute CoT.

## Key takeaways

- CoT base event is deliberately terse with a small set of mandatory fields
- Type strings follow a hierarchical code derived from MIL-STD-2525
