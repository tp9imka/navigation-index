# Dynamic Obstacle Avoidance for Quadrotors with Event Cameras

`res:falanga-event-camera-dodging-2020` - paper - <https://www.zora.uzh.ch/entities/publication/a37f45b7-b5cc-45ea-b2c3-6c3191fb4928>

**By:** Davide Falanga, Kevin Kleber, Davide Scaramuzza - **Year:** 2020 - **Level:** advanced - **Access:** open

Uses event timing to split moving from static objects and commands a dodge, with about 3.5 ms latency, against objects at relative speeds up to 10 m/s, onboard only. Science Robotics 5(40), doi 10.1126/scirobotics.aaz9712.

## Key takeaways

- Latency is the limit for dynamic obstacles
- Needs event-camera hardware
