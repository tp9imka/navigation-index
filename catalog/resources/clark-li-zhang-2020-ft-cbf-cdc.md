# Control Barrier Functions for Safe CPS Under Sensor Faults and Attacks

`res:clark-li-zhang-2020-ft-cbf-cdc` - paper - <https://par.nsf.gov/servlets/purl/10310663>

**By:** Andrew Clark, Zhouchi Li, Hongchao Zhang - **Year:** 2020 - **Level:** advanced - **Access:** open

Peer-reviewed (59th IEEE CDC 2020, pp. 796-803). Conference version of fault-tolerant CBFs: keep several state estimators, each ignoring the sensors of one fault pattern, and impose a CBF constraint per estimator so the stochastic system stays safe under any single fault pattern. Earliest found statement of the fault-hypothesis-bank safety filter.

## Key takeaways

- Priority date for the idea of a CBF safety filter driven by fault-excluded estimator subsets is 2020
- A judge can name it as prior art for any PL-margin safety filter
