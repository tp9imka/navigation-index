# Probabilistic roadmaps for path planning in high-dimensional configuration spaces

`res:kavraki-prm-1996` - paper - <https://doi.org/10.1109/70.508439>

**By:** Lydia E. Kavraki, Petr Svestka, Jean-Claude Latombe, Mark H. Overmars - **Year:** 1996 - **Level:** intro - **Access:** paywalled

Peer-reviewed (IEEE Transactions on Robotics and Automation). Defines the probabilistic roadmap: sample free configurations, connect neighbours with a local planner, then answer queries with graph search.

## Key takeaways

- Build once, query many times: suits a static known close area
- Coverage of narrow passages depends on sampling density
- Local planner choice decides roadmap quality
