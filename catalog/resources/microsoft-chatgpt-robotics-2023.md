# ChatGPT for Robotics: Design Principles and Model Abilities

`res:microsoft-chatgpt-robotics-2023` - paper - <https://arxiv.org/abs/2306.17582>

**By:** Vemprala et al., Microsoft - **Year:** 2023 - **Level:** intro - **Access:** open

Early study of prompting strategies and API design for using ChatGPT to generate robot and drone control code, with AirSim demos.

## Key takeaways

- Expose a high-level function library to the LLM
- Keep a human in the loop to review code
