# RFC 5905: Network Time Protocol Version 4: Protocol and Algorithms Specification

`res:rfc5905-ntpv4` - standard - <https://www.rfc-editor.org/rfc/rfc5905>

**By:** D. Mills, J. Martin, J. Burbank, W. Kasch - **Year:** 2010 - **Level:** advanced - **Access:** open

The NTPv4 specification: on-wire protocol, clock filter, selection and clustering algorithms, and the clock discipline loop.

## Key takeaways

- Selection and clustering reject falsetickers when several servers are used
- The discipline algorithm is a hybrid phase/frequency loop
