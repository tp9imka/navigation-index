# Time Guidance for Network Operators, Chief Information Officers, and Chief Information Security Officers

`res:cisa-time-guidance-network-operators` - doc - <https://www.cisa.gov/publication/time-guidance-network-operators-cios-cisos>

**By:** CISA - **Year:** 2022 - **Level:** intro - **Access:** open

CISA guidance on making enterprise time resilient and secure: know where time comes from, use several independent sources, detect anomalies in timing sources, and test. The 2022 update added network considerations from a tabletop pilot plus self-assessment questions and a test plan.

## Key takeaways

- Inventory every time dependency and its upstream source
- Use multiple, diverse time sources and compare them
- Detect and handle anomalies in time sources; test the response
