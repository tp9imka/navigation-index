# Brave1 запускає лабораторію для тестування CRPA-антен

**By:** Militarnyi - **Year:** 2024 - **Level:** intro - **Access:** open

English: 'Brave1 launches a lab for testing CRPA antennas'. Ukraine's defense-tech cluster opened a lab with EW equipment where domestic developers can test anti-jam GNSS antenna prototypes against jamming and get feedback before fielding. Test procedures are not described.

## Key takeaways

- Ukraine treats anti-jam GNSS antennas as a domestic product category with a dedicated test facility
- Testing against real EW emitters is the gate before field use
- Shows the government-cluster model (Brave1) for EW-resilience hardware
