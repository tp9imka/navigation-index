# PX4 Developer Summit (talks and recordings)

`res:px4-developer-summit` - talk - <https://events.linuxfoundation.org/px4-developer-summit/>

**By:** Dronecode Foundation, Linux Foundation - **Year:** 2025 - **Level:** intermediate - **Access:** open

Annual PX4 developer conference; recordings are posted on the PX4 YouTube channel. The 2025 Atlanta programme included an EKF2 session on handling multiple data sources with 'reset by fusion' rather than hard resets.

## Key takeaways

- Primary source on EKF2 design changes
- Talks on external vision/non-GNSS aiding in PX4
