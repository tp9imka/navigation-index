# Навигация по снимкам местности на основе сопоставления глубоких признаков и визуальной одометрии

`res:bntu-rulko-terrain-nav-deep-features-2025` - paper - <https://rep.bntu.by/handle/data/154717>

**By:** E. V. Rulko - **Year:** 2025 - **Level:** advanced - **Access:** open

English: 'Terrain relative navigation based on deep feature template matching and visual odometry'. Belarusian journal article: self-supervised (triplet-loss) deep features for matching UAV views to satellite patches across season, weather and lighting; visual odometry bridges featureless forest/field areas; an entropy filter plus path planning steers flights over feature-rich terrain.

## Key takeaways

- Plan the route over informative terrain instead of only improving the matcher
- Self-supervised features avoid labelled cross-season data
- VO bridges texture-poor segments between absolute fixes
