# Complementary PNT and GPS Backup Technologies Demonstration Report

`res:dot-complementary-pnt-report-2021` - report - <https://rosap.ntl.bts.gov/view/dot/55765>

**By:** U.S. DOT Volpe Center - **Year:** 2021 - **Level:** intermediate - **Access:** open

Field demonstration of 11 GPS-backup technologies (including eLoran, terrestrial beacons, LEO and fiber timing) against defined scenarios, delivered to Congress.

## Key takeaways

- No single technology fully backs up GPS
- eLoran fails differently from GNSS, which is its value
