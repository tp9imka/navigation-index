# 28 із 37 деталей - зі США: ГУР МО розкрило склад іноземних компонентів у російських «Кометах»

**By:** Militarnyi, HUR MO Ukraine - **Year:** 2026 - **Level:** intro - **Access:** open

English: '28 of 37 parts from the US: HUR disclosed foreign components in Russian Kometa modules'. Teardown-level description of the Kometa CRPA: a patch-element array plus a processing module built around an Altera Cyclone FPGA; 16-element versions widely fielded, 20-element in preparation, and 32-element arrays documented on downed drones. Lists the origin of 37 foreign components.

## Key takeaways

- CRPA = antenna array + FPGA beamforming; spatial rejection grows with element count
- Gives a concrete architecture for anyone modelling anti-jam receivers
- No RF front-end or channel specs disclosed
