# Oxford RobotCar Dataset

`res:oxford-robotcar-dataset` - dataset - <https://robotcar-dataset.robots.ox.ac.uk/>

**By:** Oxford Robotics Institute - **Year:** 2016 - **Level:** intermediate - **Access:** free-registration

Repeated drives of the same Oxford route over a year in all weather, with cameras, lidar and GPS/INS.

## Key takeaways

- Sensors: cameras, lidar, GPS/INS
- Size class: very large
