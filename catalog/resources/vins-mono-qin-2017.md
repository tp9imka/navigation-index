# VINS-Mono: A Robust and Versatile Monocular Visual-Inertial State Estimator

`res:vins-mono-qin-2017` - paper - <https://arxiv.org/abs/1708.03852>

**By:** Tong Qin, Peiliang Li, Shaojie Shen - **Year:** 2017 - **Level:** advanced - **Access:** open

Presents the VINS-Mono estimator: IMU preintegration, robust initialization, tightly coupled sliding-window optimization, relocalization and global pose graph.

## Key takeaways

- Monocular camera + IMU recovers metric scale
- Initialization is a key practical component
