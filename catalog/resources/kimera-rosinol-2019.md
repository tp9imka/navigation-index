# Kimera: an Open-Source Library for Real-Time Metric-Semantic Localization and Mapping

`res:kimera-rosinol-2019` - paper - <https://arxiv.org/abs/1910.02490>

**By:** Antoni Rosinol, Marcus Abate, Yun Chang, Luca Carlone - **Year:** 2019 - **Level:** advanced - **Access:** open

Describes the Kimera stack: VIO, robust pose-graph optimization, mesh reconstruction and semantic mapping in one open library.

## Key takeaways

- Metric-semantic maps on CPU in real time
- Modular: VIO, RPGO, mesher, semantics
