# CityNav: A Large-Scale Dataset for Real-World Aerial Navigation

`res:citynav-2024` - paper - <https://arxiv.org/abs/2406.14240>

**By:** Lee et al. - **Year:** 2024 - **Level:** advanced - **Access:** open

Introduces a language-goal aerial navigation dataset built on real-city 3D data with geographic metadata, and baselines using map-based grounding.

## Key takeaways

- Geographic map priors improve aerial language navigation
- Human demonstrations from a web simulator
