# Above Us Only Stars: Exposing GPS Spoofing in Russia and Syria

`res:c4ads-above-us-only-stars` - report - <https://c4ads.org/reports/above-us-only-stars/>

**By:** C4ADS - **Year:** 2019 - **Level:** intermediate - **Access:** open

Open-source investigation using AIS ship tracks, public records and ISS-based measurements to map thousands of GNSS spoofing events around Russia, Crimea and Syria, many linked to protection of VIPs and bases.

## Key takeaways

- Shows how public data (AIS) reveals spoofing via impossible tracks
- Spoofing used for airspace denial around military facilities
- A model for OSINT-style interference detection projects
- AIS position anomalies reveal spoofing at scale
- Methodology is reproducible with public data
