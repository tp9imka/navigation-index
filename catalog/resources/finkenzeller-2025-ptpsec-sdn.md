# Securing the Precision Time Protocol with SDN-enabled Cyclic Path Asymmetry Analysis

`res:finkenzeller-2025-ptpsec-sdn` - paper - <https://zenodo.org/records/17294266>

**By:** Andreas Finkenzeller, Arne Fucks, Emanuel Regnath, Mohammad Hamad, Sebastian Steinhorst - **Year:** 2025 - **Level:** advanced - **Access:** open

Follow-up to PTPsec that uses software-defined networking to find redundant paths dynamically in arbitrary topologies and then runs the cyclic path asymmetry check against delay attacks. Open-access PDF on Zenodo (CC BY 4.0).

## Key takeaways

- Removes PTPsec's need for hand-configured redundant paths
- Useful reference for a delay-attack detection demo on a small switched testbed
