# Perception-aware Planning for Quadrotor Flight in Unknown and Feature-limited Environments

`res:yu-la-planner-perception-aware-2025` - paper - <https://arxiv.org/abs/2503.15273>

**By:** Chenxin Yu, Zihong Lu, Jie Mei, Boyu Zhou - **Year:** 2025 - **Level:** advanced - **Access:** open

Localisation-aware planner that reasons about which features the camera will see along candidate trajectories and steers yaw and path to keep VIO healthy in sparse-feature scenes (IROS 2025).

## Key takeaways

- Recent evidence that localisation-aware planning is active research
- Couples yaw planning with feature visibility
- Code is public under GPL-3.0
