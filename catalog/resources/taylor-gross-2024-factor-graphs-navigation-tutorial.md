# Factor Graphs for Navigation Applications: A Tutorial

`res:taylor-gross-2024-factor-graphs-navigation-tutorial` - paper - <https://navi.ion.org/content/71/3/navi.653>

**By:** Clark Taylor, Jason Gross - **Year:** 2024 - **Level:** intermediate - **Access:** open

NAVIGATION (ION journal) 71(3), 2024, open access. Introduces factor graphs as a generalisation of the Kalman filter for navigation engineers, compares EKF, batch and sliding-window estimators on the same problem, and surveys navigation uses.

## Key takeaways

- Written for people who think in EKFs
- Companion Python code compares all three estimators
- Good slide source for 'why a factor graph for plug-and-play'
