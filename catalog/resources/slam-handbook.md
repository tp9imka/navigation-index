# SLAM Handbook: From Localization and Mapping to Spatial Intelligence

`res:slam-handbook` - book - <https://github.com/SLAM-Handbook-contributors/slam-handbook-public-release>

**By:** Luca Carlone, Ayoung Kim, Timothy Barfoot, Daniel Cremers, Frank Dellaert (eds.), Frank Dellaert - **Year:** 2025 - **Level:** advanced - **Access:** open

Community-written handbook released in three parts during 2024-2025 and published by Cambridge University Press; the free PDF is mirrored on the editors' project page. Covers factor graphs, Lie groups, robust estimation, certifiable methods, visual/LiDAR/radar/event-based SLAM, and learned spatial representations.

## Key takeaways

- Most current one-stop reference on SLAM (2025)
- Chapters on non-visual sensors such as radar
- Free PDF; GitHub repo tracks newest release
- Single up-to-date reference spanning classic estimation and learned methods
- Free chapter PDFs on GitHub

**Concepts:** [Visual SLAM](../concepts/visual-slam.md), [LiDAR odometry and SLAM](../concepts/lidar-slam.md), [Radar navigation and odometry](../concepts/radar-nav.md), [Visual(-inertial) odometry](../concepts/vio.md), [Sensor fusion and state estimation](../concepts/sensor-fusion.md)
