# Small Unmanned Aircraft: Theory and Practice

`res:beard-mclain-small-unmanned-aircraft` - book - <https://github.com/byu-magicc/mavsim_public>

**By:** Randal W. Beard, Timothy W. McLain - **Year:** 2012 - **Level:** intro - **Access:** open

Textbook covering fixed-wing dynamics, autopilot design, state estimation, straight-line and orbit path following, Dubins path management and path planning. The repo README links a draft second edition PDF and chapter slides.

- Chapters 10-12 are the guidance and planning core
- Draft second edition is free via the repo README; the 2012 print edition is Princeton University Press
- Pairs with runnable Python project files in the same repo
