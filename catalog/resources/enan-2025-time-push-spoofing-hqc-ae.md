# Quantum-Classical Hybrid Framework for Zero-Day Time-Push GNSS Spoofing Detection

`res:enan-2025-time-push-spoofing-hqc-ae` - paper - <https://arxiv.org/abs/2508.18085>

**By:** Abyad Enan, Mashrur Chowdhury, Sagar Dasgupta, Mizanur Rahman - **Year:** 2025 - **Level:** advanced - **Access:** open

Preprint on detecting time-push spoofing against static GNSS receivers with an autoencoder (hybrid quantum-classical) trained only on authentic tracking-stage features, so it can flag unseen attack types. Compared with classical autoencoders and supervised models across simplistic, intermediate and sophisticated time-push scenarios.

## Key takeaways

- Anomaly detection trained on clean data only
- Focus on time-push attacks on static timing receivers
- Quantum part is optional for a hackathon; the classical baseline is the useful bit
