# Terrain Contour Matching (TERCOM): A Cruise Missile Guidance Aid

`res:golden-1980-tercom` - paper - <https://doi.org/10.1117/12.959127>

**By:** Joe P. Golden - **Year:** 1980 - **Level:** intro - **Access:** paywalled

Proc. SPIE 0238 paper giving a brief history of TERCOM, how terrain contour matching works (correlating a measured altitude profile against stored elevation data) and its status in 1980. It is the standard English citation for the origin of terrain-correlation navigation; this index uses it only for the navigation-update concept.

## Key takeaways

- Batch profile correlation against a stored elevation map
- Historic baseline that later sequential filters (SITAN, PMF, PF) improved on
- Abstract only without SPIE access
