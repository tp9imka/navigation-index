# Signal Enhancement for Magnetic Navigation Challenge Problem

`res:afrl-magnav-challenge-2020` - paper - <https://arxiv.org/abs/2007.12158>

**By:** Albert R. Gnadt, Joseph Belarge, Aaron Canciani et al. - **Year:** 2020 - **Level:** intermediate - **Access:** open

Defines the MagNav challenge from the DAF-MIT AI Accelerator: separate the Earth's magnetic anomaly signal from aircraft interference using real flight data, framed as a scientific machine-learning problem.

## Key takeaways

- Aircraft magnetic compensation is the core difficulty
- Provides real survey-flight data and a baseline
