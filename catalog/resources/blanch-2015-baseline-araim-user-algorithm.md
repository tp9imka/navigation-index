# Baseline advanced RAIM user algorithm and possible improvements

`res:blanch-2015-baseline-araim-user-algorithm` - paper - <https://doi.org/10.1109/TAES.2014.130739>

**By:** Juan Blanch, Todd Walter, Per Enge, Young Lee, Boris Pervan, Markus Rippl, Alex Spletter, Victoria Kropp - **Year:** 2015 - **Level:** advanced - **Access:** paywalled

IEEE TAES 51(1) description of the baseline multi-fault, multi-constellation ARAIM user algorithm for LPV-200 vertical guidance. It covers pseudorange processing, nominal error models and prior fault probabilities to compute protection levels, how to choose which fault modes to monitor, fault exclusion, and a list of possible improvements.

## Key takeaways

- The reference ARAIM user algorithm in journal form
- Protection levels from solution separation over monitored fault modes
- Implemented in Stanford's MAAST tool
