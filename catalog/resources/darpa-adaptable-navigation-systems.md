# Adaptable Navigation Systems (ANS)

`res:darpa-adaptable-navigation-systems` - doc - <https://www.darpa.mil/research/programs/adaptable-navigation-systems>

**By:** DARPA - **Year:** 2014 - **Level:** intro - **Access:** open

DARPA program page for ANS, which pursued GPS-quality PNT in denied environments through precision inertial sensors (PINS) and the All Source Positioning and Navigation (ASPN) sensor-fusion effort.

## Key takeaways

- ASPN aimed at plug-and-play fusion of many nav sensors
- Framed GNSS denial as a core military problem
- Combined ASPN-style sensor fusion with new IMU technology
- Explicit focus on reconfigurable multi-sensor navigation
