# Loc-NeRF: Monte Carlo Localization using Neural Radiance Fields

`res:maggio-2022-loc-nerf` - paper - <https://arxiv.org/abs/2209.09050>

**By:** Dominic Maggio, Marcus Abate, Jingnan Shi, Courtney Mario - **Year:** 2022 - **Level:** advanced - **Access:** open

Particle-filter localization of a camera against a NeRF map. The reference for using a neural field as the map inside a Monte Carlo localizer.

## Key takeaways

- MIT code
- Camera against a radiance field, not elevation against a DEM
