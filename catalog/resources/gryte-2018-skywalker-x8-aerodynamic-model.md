# Aerodynamic modeling of the Skywalker X8 Fixed-Wing Unmanned Aerial Vehicle

`res:gryte-2018-skywalker-x8-aerodynamic-model` - paper - <https://folk.ntnu.no/torarnj/icuasX8.pdf>

**By:** Kristoffer Gryte, Richard Hann, Mushfiqul Alam, Jan Rohac, Tor Arne Johansen, Thor I. Fossen - **Year:** 2018 - **Level:** intermediate - **Access:** open

ICUAS 2018. Identifies a full aerodynamic coefficient set for the Skywalker X8 flying wing from CFD, wind tunnel and flight data; the model is published in a companion MATLAB repo.

## Key takeaways

- Ready-made aero coefficients for a common small fixed-wing
- Thrust model in the repo is borrowed, not identified
- Enough to build a VDM process model in hours
