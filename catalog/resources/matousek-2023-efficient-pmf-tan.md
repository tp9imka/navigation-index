# Design of Efficient Point-Mass Filter with Application in Terrain Aided Navigation

`res:matousek-2023-efficient-pmf-tan` - paper - <https://arxiv.org/abs/2303.05100>

**By:** J. Matousek, J. Dunik, M. Brandner - **Year:** 2023 - **Level:** advanced - **Access:** open

FUSION 2023 paper on speeding up the time-update (prediction) step of the grid-based point-mass filter for models with linear dynamics, unifying continuous and discrete formulations. The authors report large time-complexity reductions without accuracy loss in a terrain-aided navigation example, and release MATLAB code.

## Key takeaways

- Makes the PMF cheap enough for real-time TAN
- MATLAB code on GitHub
- Good modern successor to Bergman's PMF
