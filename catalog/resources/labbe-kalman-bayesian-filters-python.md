# Kalman and Bayesian Filters in Python

`res:labbe-kalman-bayesian-filters-python` - book - <https://github.com/rlabbe/Kalman-and-Bayesian-Filters-in-Python>

**By:** Roger R. Labbe Jr. - **Year:** 2020 - **Level:** intro - **Access:** open

Free interactive book as Jupyter notebooks: g-h filters, discrete Bayes, univariate and multivariate Kalman filters, EKF, UKF, particle filters and smoothers, all with runnable code built on the companion FilterPy library.

## Key takeaways

- Intuition-first, code-first; ideal for teammates new to filtering
- Notebooks run in Binder or locally
- FilterPy gives drop-in KF/EKF/UKF classes for prototypes
