# Высокоточная навигация GNSS RTK

`res:habr-zed-f9p-rtk-2022` - blog - <https://habr.com/ru/articles/648247/>

**By:** aabzel - **Year:** 2022 - **Level:** intro - **Access:** open

English: 'High-precision GNSS RTK navigation'. Hands-on review of the u-blox ZED-F9P: tracing letters and spinning the antenna on a carousel to visualise RTK Fixed track quality. Comments add practical limits (lower RTK rate with more constellations, LoRa correction links, urban canyon dropouts).

## Key takeaways

- Simple visual tests (carousel, letters) expose RTK fix quality without survey gear
- RTK output rate drops with the number of constellations
- Comment thread has DIY base-station experience
