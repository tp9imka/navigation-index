# DEIO: Deep Event Inertial Odometry

`res:guan-2025-deio-event-inertial-odometry` - paper - <https://arxiv.org/abs/2411.03928>

**By:** Weipeng Guan, Fuling Lin, Peiyu Chen, Peng Lu - **Year:** 2025 - **Level:** advanced - **Access:** open

Learning-based event-inertial odometry evaluated on 10 public benchmarks against more than 20 methods. The authors' repo labels it ICCV 2025; arXiv lists no venue.

## Key takeaways

- Learned event front-end plus IMU in a factor graph
- MIT-licensed code
- Needs event-camera data; no aerial night-flight number checked here
