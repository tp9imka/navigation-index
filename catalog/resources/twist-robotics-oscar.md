# Twist Robotics OSCAR visual navigation module (Ukraine)

`res:twist-robotics-oscar` - product - <https://www.pravda.com.ua/eng/news/2026/01/28/8018266>

**By:** Twist Robotics - **Year:** 2026 - **Level:** intermediate - **Access:** open

Ukrainian company Twist Robotics announced OSCAR in January 2026: a camera-based module that recognises landmarks, matches them to a map and feeds coordinates to the UAV autopilot when GNSS is jammed.

## Key takeaways

- Vendor claim: platforms with the module have flown more than 500,000 km
- Architecture (camera => map match => coordinates into autopilot) is the same one open repos implement
