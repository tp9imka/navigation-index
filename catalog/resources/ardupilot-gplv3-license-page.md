# ArduPilot License (GPLv3)

`res:ardupilot-gplv3-license-page` - doc - <https://ardupilot.org/dev/docs/license-gplv3.html>

**By:** ArduPilot - **Year:** 2026 - **Level:** intro - **Access:** open

ArduPilot's own reading of its GPLv3 obligations for products: tell customers it is open source, provide source or a link, keep credits, and respect upgrade rights on user products. States that closed-source code can run on a companion computer.

## Key takeaways

- Shipping modified ArduPilot firmware means shipping its source
- A closed nav algorithm belongs on the companion, talking MAVLink
- Does not itself address where MAVLink communication sits legally; see the GPL FAQ
