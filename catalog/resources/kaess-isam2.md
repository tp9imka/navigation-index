# iSAM2: Incremental Smoothing and Mapping Using the Bayes Tree

`res:kaess-isam2` - paper - <https://www.cs.cmu.edu/~kaess/pub/Kaess12ijrr.pdf>

**By:** Michael Kaess, Hordur Johannsson, Richard Roberts, Viorela Ila, John Leonard, Frank Dellaert - **Year:** 2012 - **Level:** advanced - **Access:** open

Introduces the Bayes tree and the iSAM2 algorithm for incremental nonlinear smoothing with fluid relinearization, the engine behind GTSAM's online estimators.

## Key takeaways

- Incremental updates without periodic batch steps
- Bayes tree data structure
