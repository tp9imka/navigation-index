# Galileo Open Service Signal-In-Space Interface Control Document (OS SIS ICD) Issue 2.1

`res:galileo-os-sis-icd-2-1` - standard - <https://www.gsc-europa.eu/sites/default/files/sites/all/files/Galileo_OS_SIS_ICD_v2.1.pdf>

**By:** EU / European GNSS Service Centre, European Union / EUSPA - **Year:** 2023 - **Level:** advanced - **Access:** open

Specification of the Galileo open service signals (E1, E5a, E5b, E6 at the structure level) and the F/NAV and I/NAV navigation messages. Needed for any multi-constellation receiver or Galileo decoder.

## Key takeaways

- Defines I/NAV and F/NAV page layouts
- Ranging code and modulation details for E1 and E5
- Newer issues are listed in the GSC reference documents library
- Required for decoding Galileo navigation data
- I/NAV is the carrier for OSNMA bits
