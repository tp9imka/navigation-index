# «Ми почали будувати захищену екосистему для всіх військових застосунків». Архітектор DELTA - про розвиток системи

`res:dou-delta-architecture-interview-2024` - blog - <https://dou.ua/lenta/interviews/delta-challenges-and-plans/>

**By:** Eleonora Burdina, DOU.ua, Artem Martynenko (interviewee, MoD Innovation Center) - **Year:** 2024 - **Level:** intro - **Access:** open

English: 'We started building a secure ecosystem for all military applications. DELTA's architect on the system's development'. Interview on Ukraine's DELTA situational-awareness system: a shared core fed by aerial recon, satellites, drones and radars; a map as one view; a synchronization matrix linking drone missions to map objects; streaming, chat with zone alerts, mobile app, AI video detection; security built on NIST 800-53 and FIDO2.

## Key takeaways

- SA systems in Ukraine evolved from a single map into a product ecosystem on a common data core
- Contrasted with the NATO model of separate systems joined by custom integration
- Security baseline cited: NIST 800-53 and FIDO2 phishing-resistant auth
- Offline/edge operation is not discussed
