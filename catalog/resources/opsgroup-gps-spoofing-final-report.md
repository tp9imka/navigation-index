# OPSGROUP GPS Spoofing Workgroup Final Report

`res:opsgroup-gps-spoofing-final-report` - report - <https://ops.group/blog/gps-spoofing-final-report/>

**By:** OPSGROUP GPS Spoofing Workgroup - **Year:** 2024 - **Level:** intro - **Access:** open

Large practitioner-driven report on airliner GPS spoofing, built from crew surveys and incident data, with recommendations to manufacturers, regulators and operators. The best ground-truth account of what spoofing does to real avionics.

## Key takeaways

- Spoofing can leave systems like terrain warning degraded after GPS returns
- Receivers may retain corrupted data after an event
- Argues for retaining ground-based navaids
