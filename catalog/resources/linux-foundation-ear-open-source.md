# The EAR and Open Source Software

`res:linux-foundation-ear-open-source` - doc - <https://bestpractices.linuxfoundation.org/regulatory/export/ear-oss.html>

**By:** Linux Foundation - **Year:** 2024 - **Level:** intro - **Access:** open

Practical guide to how US Export Administration Regulations treat published open-source code, including the separate notification step for encryption.

## Key takeaways

- Code published without restriction is generally outside the EAR
- Encryption source has an extra BIS/NSA notification step
- Private repos shared with foreign nationals can count as exports
