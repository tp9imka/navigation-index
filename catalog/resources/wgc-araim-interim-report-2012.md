# EU-U.S. Cooperation on Satellite Navigation, Working Group C, ARAIM Technical Subgroup - Interim Report (Issue 1.0)

`res:wgc-araim-interim-report-2012` - report - <https://archive.gps.gov/policy/cooperation/europe/2013/working-group-c/ARAIM-report-1.0.pdf>

**By:** EU-U.S. Cooperation on Satellite Navigation, Working Group C - ARAIM Technical Subgroup - **Year:** 2012 - **Level:** advanced - **Access:** open

First (Milestone 1) report of the EU-US ARAIM subgroup, dated 19 December 2012, prepared by FAA, Stanford, MITRE, IIT, DLR, UniBW Munich, ESA and the European Commission. It gives an ARAIM overview, the requirements analysis for global LPV-200 vertical guidance, a reference user algorithm, first performance evaluation and the identified threats.

## Key takeaways

- Why ARAIM: multi-constellation integrity with ground-supplied fault rates
- LPV-200 as the driving requirement
- First reference air algorithm
