# MIL-STD-2525 Joint Military Symbology - overview

`res:mil-std-2525-overview` - doc - <https://en.wikipedia.org/wiki/MIL-STD-2525>

**By:** US DoD (summary: Wikipedia) - **Year:** 2023 - **Level:** intro - **Access:** open

Summary of the US military symbology standard and its revisions (2525B through E), including the SIDC code formats that symbol renderers and CoT type strings map onto.

## Key takeaways

- 2525D/E moved to a numeric 20/30-digit SIDC
- Basis for symbology in TAK and many C2 tools
