# EU-U.S. Cooperation on Satellite Navigation, Working Group C - ARAIM Technical Subgroup - Milestone 3 Report

`res:wgc-araim-milestone-3-report-2016` - report - <https://archive.gps.gov/policy/cooperation/europe/2016/working-group-c/ARAIM-milestone-3-report.pdf>

**By:** EU-U.S. Cooperation on Satellite Navigation, Working Group C - ARAIM Technical Subgroup - **Year:** 2016 - **Level:** advanced - **Access:** open

Final version dated 25 February 2016, concluding the three-phase effort. Adds the proposed ARAIM implementation roadmap, message types for H-ARAIM and for offline and online vertical ARAIM, institutional issues, the relation to SBAS, H-ARAIM availability results and the updated reference user algorithm (Annex A). Also hosted by the European Commission.

## Key takeaways

- Roadmap toward ARAIM standards
- Message definitions per ARAIM mode
- Latest reference user algorithm in Annex A
