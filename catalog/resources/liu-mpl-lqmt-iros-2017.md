# Search-based motion planning for quadrotors using linear quadratic minimum time control

`res:liu-mpl-lqmt-iros-2017` - paper - <https://doi.org/10.1109/IROS.2017.8206119>

**By:** Sikang Liu, Nikolay Atanasov, Kartik Mohta, Vijay Kumar - **Year:** 2017 - **Level:** advanced - **Access:** paywalled

Peer-reviewed (IROS 2017). Kinodynamic graph search over short motion primitives with a cost that trades time against control effort, producing dynamically feasible trajectories directly.

## Key takeaways

- Search over primitives instead of grid cells gives feasible output
- Cost to go is a minimum-time plus effort heuristic
- Slower than geometric search in high dimensions
