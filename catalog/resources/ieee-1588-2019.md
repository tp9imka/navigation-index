# IEEE 1588-2019: IEEE Standard for a Precision Clock Synchronization Protocol for Networked Measurement and Control Systems

`res:ieee-1588-2019` - standard - <https://standards.ieee.org/ieee/1588/6825/>

**By:** IEEE - **Year:** 2020 - **Level:** advanced - **Access:** paywalled

The PTP standard (version 2.1), approved November 2019 and published June 2020. Defines ordinary, boundary and transparent clocks, profiles and an optional security mechanism.

## Key takeaways

- PTP accuracy depends on hardware timestamping and symmetric paths
- The 2019 edition adds optional security mechanisms
