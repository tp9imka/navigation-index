# Path Planning for Autonomous Vehicles in Unknown Semi-structured Environments

`res:dolgov-hybrid-astar-ijrr-2010` - paper - <https://doi.org/10.1177/0278364909359210>

**By:** Dmitri Dolgov, Sebastian Thrun, Michael Montemerlo, James Diebel - **Year:** 2010 - **Level:** intermediate - **Access:** paywalled

Peer-reviewed (IJRR). The Hybrid A* paper from the DARPA Urban Challenge: A* over a discretised grid where each node keeps a continuous state reached by kinematically feasible motions, followed by numerical smoothing.

## Key takeaways

- Grid for pruning, continuous state for feasibility
- Built for curvature-limited ground vehicles
- For multirotors, kinodynamic search with motion primitives is the analogue
