# Analyzing a More Resilient National Positioning, Navigation, and Timing Capability (RR-2970)

`res:rand-rr2970-resilient-pnt` - report - <https://www.rand.org/pubs/research_reports/RR2970.html>

**By:** RAND Corporation - **Year:** 2021 - **Level:** intermediate - **Access:** open

DHS-sponsored RAND study of civil US PNT dependence that argues GPS is not the only PNT source in practice and that no single system is a perfect backup. It is a deliberately contrarian counterweight to the 'GPS loss is catastrophic' framing.

## Key takeaways

- Realistic adaptation lowers estimated economic cost of GPS loss
- High bar for a large government-funded GPS backup
- Recommends modest investment in threat detection
