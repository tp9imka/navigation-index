# A Software-Defined GPS and Galileo Receiver: A Single-Frequency Approach

`res:borre-software-defined-gps-galileo-receiver` - book - <https://ccar.colorado.edu/gnss>

**By:** K. Borre, D. Akos, N. Bertelsen, P. Rinder, S.H. Jensen, Kai Borre, Dennis M. Akos, Nicolaj Bertelsen, Peter Rinder, Søren Holdt Jensen - **Year:** 2007 - **Level:** intermediate - **Access:** paywalled

Classic textbook that walks through a complete MATLAB GPS software receiver: acquisition, code/carrier tracking, navigation decoding and positioning. The linked University of Colorado page is the official support site for the book's code.

## Key takeaways

- The canonical entry point to SDR GNSS receivers
- MATLAB code makes every loop inspectable
- Foundation for many later open SDR receivers
- Teaches acquisition and tracking loops by code
- Still the standard SDR GNSS teaching text
