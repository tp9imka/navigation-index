# Autonomous GPS Integrity Monitoring Using the Pseudorange Residual

`res:parkinson-axelrad-1988-raim-pseudorange-residual` - paper - <https://doi.org/10.1002/j.2161-4296.1988.tb00955.x>

**By:** Bradford W. Parkinson, Penina Axelrad - **Year:** 1988 - **Level:** advanced - **Access:** paywalled

NAVIGATION 35(2) paper proposing satellite failure detection and isolation from the least-squares pseudorange residual, one of the founding RAIM formulations. Detection uses the range residual test statistic when six or more satellites are in view.

## Key takeaways

- Residual-based RAIM origin
- Detection and isolation from the over-determined solution
- Background for every later FDE scheme
