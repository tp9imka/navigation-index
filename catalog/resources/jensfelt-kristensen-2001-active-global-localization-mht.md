# Active Global Localization for a Mobile Robot Using Multiple Hypothesis Tracking

`res:jensfelt-kristensen-2001-active-global-localization-mht` - paper - <https://www.csc.kth.se/~patric/publications/berlinMHT.html>

**By:** Patric Jensfelt, Steen Kristensen - **Year:** 2001 - **Level:** intermediate - **Access:** open

IEEE Transactions on Robotics and Automation 17(5). Tracks several Gaussian pose hypotheses with Kalman filters, scores the probability that each is correct, and issues motion commands that gather information. Tested in an office and a hospital building. Abstract only read.

## Key takeaways

- Multi-hypothesis tracking is a cheaper alternative to a grid or particle belief
- Motion is chosen to help hypothesis scoring, not only to reach a goal
