# ALFA: A dataset for UAV fault and anomaly detection

`res:keipour-2021-alfa-dataset` - paper - <https://arxiv.org/abs/1907.06268>

**By:** Azarakhsh Keipour, Mohammadreza Mousaei, Sebastian Scherer - **Year:** 2021 - **Level:** intermediate - **Access:** open

International Journal of Robotics Research 40(2-3), 2021. Describes 47 autonomous fixed-wing flights with eight fault types (engine and control surfaces), fault-time ground truth, and evaluation metrics. Data on KiltHub (DOI 10.1184/R1/12707963).

## Key takeaways

- Real ArduPilot fixed-wing logs with GPS truth
- Engine-out segments test a propulsion model's failure mode
- KiltHub metadata says CC BY 4.0; bundled README says CC0
