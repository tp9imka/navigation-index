# The EuRoC MAV Dataset

`res:ethz-euroc-mav-dataset` - dataset - <https://projects.asl.ethz.ch/datasets/doku.php?id=kmavvisualinertialdatasets>

**By:** ETH Zurich ASL - **Year:** 2016 - **Level:** intro - **Access:** open

Stereo camera and IMU sequences from a micro aerial vehicle in an industrial hall and a Vicon room, with laser-tracker or motion-capture ground truth. The baseline benchmark for VIO.

## Key takeaways

- Sensors: stereo grayscale, IMU
- Size class: small (GB range)
- Use for first VIO sanity checks
