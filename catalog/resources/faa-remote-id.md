# FAA - Remote Identification of Drones

`res:faa-remote-id` - doc - <https://www.faa.gov/uas/getting_started/remote_id>

**By:** US Federal Aviation Administration - **Year:** 2024 - **Level:** intro - **Access:** open

FAA guidance on the Remote ID rule: what drones must broadcast, standard vs broadcast-module compliance and operator obligations.

## Key takeaways

- Remote ID gives a lawful, cooperative signal for drone awareness
- Defines what fields you can expect to decode
- Standard Remote ID broadcasts drone and control station location
- Non-compliant drones need non-cooperative detection
