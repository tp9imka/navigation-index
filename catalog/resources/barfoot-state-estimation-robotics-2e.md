# State Estimation for Robotics (Second Edition)

`res:barfoot-state-estimation-robotics-2e` - book - <http://asrl.utias.utoronto.ca/~tdb/bib/barfoot_ser24.pdf>

**By:** Timothy D. Barfoot - **Year:** 2024 - **Level:** advanced - **Access:** open

Textbook on probabilistic estimation for robotics, from linear-Gaussian filtering and batch estimation to matrix Lie groups for 3D pose; the second edition adds variational inference and inertial navigation material. Author hosts a PDF; print edition from Cambridge University Press.

## Key takeaways

- Batch vs recursive estimation from first principles
- Matrix Lie groups for pose and uncertainty
- New inertial navigation section in 2nd edition
- Rigorous treatment of SE(3) uncertainty
- Bridges filtering and batch optimization
