# Galileo OSNMA Receiver Guidelines v1.3

`res:galileo-osnma-receiver-guidelines-1-3` - standard - <https://www.gsc-europa.eu/sites/default/files/sites/all/files/Galileo_OSNMA_Receiver_Guidelines_v1.3.pdf>

**By:** European Union / EUSPA - **Year:** 2024 - **Level:** advanced - **Access:** open

Implementation guidance for OSNMA receivers covering time synchronization requirements, cryptographic material handling, and how to use authentication results in the position solution.

## Key takeaways

- Explains which attacks OSNMA does and does not stop (e.g. replay/meaconing limits)
- Covers key renewal and alert handling
