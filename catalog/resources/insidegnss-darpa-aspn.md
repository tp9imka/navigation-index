# DARPA Seeks PNT Robustness, Flexibility with All Source Positioning and Navigation Program

`res:insidegnss-darpa-aspn` - blog - <https://insidegnss.com/darpa-seeks-pnt-robustness-flexibility-with-all-source-positioning-and-navigation-program/>

**By:** Inside GNSS - **Year:** 2012 - **Level:** intro - **Access:** open

Background article on DARPA ASPN: a navigation architecture that accepts arbitrary combinations of sensors (cameras, magnetometers, radios, IMUs) with rapid reconfiguration.

## Key takeaways

- Shows the plug-and-play sensor-fusion goal that later GNSS-denied architectures inherit
- Phase 1 built algorithms and a software architecture
- Phase 2 targeted real-time fusion on SWaP-representative hardware
