# Autonomous Navigation of Small UAVs Based on Vehicle Dynamic Model

`res:khaghani-skaloud-2016-vdm-navigation-small-uavs-eurocow` - paper - <https://isprs-archives.copernicus.org/articles/XL-3-W4/117/2016/>

**By:** Mehran Khaghani, Jan Skaloud - **Year:** 2016 - **Level:** advanced - **Access:** open

ISPRS Archives XL-3/W4 (EuroCOW 2016), open access; journal version in NAVIGATION 63(3), 2016. Uses the vehicle dynamic model as the main process model with autopilot control inputs, corrected by IMU and GNSS, and estimates wind and model parameters inside the filter. Monte Carlo simulations report orders-of-magnitude improvement over inertial coasting for outages of a few minutes. Only the abstract was read here.
