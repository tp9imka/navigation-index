# Helsing HX-2 - map/landmark-based GNSS-denied navigation (navigation aspect only)

`res:helsing-hx2-navigation` - product - <https://shephardmedia.com/news/air-warfare/details-revealed-on-new-uas-munition-destined-for-ukraine/>

**By:** Helsing - **Year:** 2024 - **Level:** intermediate - **Access:** open

Helsing's HX-2 is a loitering UAS supplied to Ukraine. Indexed here only for its navigation approach: press reporting says an onboard computer with stored map data lets it navigate by recognising landmarks when satellite navigation is denied. Helsing navigation job postings mention vision-aided, terrain-relative, celestial and signals-of-opportunity methods.

## Key takeaways

- Press/vendor claim: landmark recognition against stored maps; no public accuracy data
- Shows the European market expects map-based visual nav as a baseline feature
