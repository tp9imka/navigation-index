# MagNav Challenge flight dataset (Zenodo)

`res:magnav-zenodo-dataset` - dataset - <https://zenodo.org/records/4271804>

**By:** DAF-MIT AI Accelerator / AFRL - **Year:** 2020 - **Level:** intermediate - **Access:** open

Zenodo record holding the MagNav challenge flight data: magnetometer, INS, GPS truth and map data from survey flights.

## Key takeaways

- HDF5 flight lines with truth position
- Paired with MagNav.jl loaders
