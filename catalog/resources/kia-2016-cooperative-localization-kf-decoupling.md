# Cooperative localization for mobile agents: a recursive decentralized algorithm based on Kalman filter decoupling

`res:kia-2016-cooperative-localization-kf-decoupling` - paper - <https://arxiv.org/abs/1505.05908>

**By:** Solmaz S. Kia, Stephen Rounds, Sonia Martinez - **Year:** 2016 - **Level:** advanced - **Access:** open

Published in IEEE Control Systems Magazine 36(2), 2016. Reviews decentralization strategies for cooperative localization with a focus on how each keeps track of inter-agent correlations, then presents a decentralized implementation of the centralized EKF in which agents propagate local intermediate variables instead of cross-covariances, and the agent that takes a relative measurement acts as an interim master for the update.

## Key takeaways

- Readable survey of CL decentralization strategies
- Exact centralized-equivalent EKF without propagating cross-covariances
- Open arXiv version
