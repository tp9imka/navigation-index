# Integrity of Visual Navigation - Developments, Challenges, and Prospects

`res:zhu-meurer-guenther-2022-integrity-visual-navigation` - paper - <https://navi.ion.org/content/69/2/navi.518>

**By:** Chen Zhu, Michael Meurer, Christoph Gunther - **Year:** 2022 - **Level:** advanced - **Access:** open

Open-access NAVIGATION 69(2) review arguing that the lack of an integrity framework is the main obstacle to using visual navigation in safety-critical roles. It reviews the state of the art and sketches a preliminary integrity description framework for feature-based visual positioning, noting that learning-based methods still lack one.

## Key takeaways

- Best single review of vision integrity
- Proposes how to describe integrity for feature-based VO/VIO
- Flags ML-based vision as an open integrity problem
