# acados: a modular open-source framework for fast embedded optimal control

`res:verschueren-acados-2019` - paper - <https://arxiv.org/abs/1910.13753>

**By:** Robin Verschueren, Gianluca Frison, Dimitris Kouzoupis, Jonathan Frey, Niels van Duijkeren, Andrea Zanelli, Branimir Novoselnik, Thivaharan Albin, Rien Quirynen, Moritz Diehl - **Year:** 2019 - **Level:** advanced - **Access:** open

Describes acados' structure-exploiting QP and SQP solvers, integrators and code generation for embedded NMPC and MHE.

## Key takeaways

- Real-time iteration SQP is the default NMPC scheme
- Models come from CasADi; C code is generated for the target
- Year is the arXiv date
