# Perception-aware Path Planning for UAVs using Semantic Segmentation

`res:bartolomei-semantic-perception-aware-iros2020` - paper - <https://lucabartolomei.github.io/publications/IROS_2020_Active_perception.pdf>

**By:** Luca Bartolomei, Lucas Teixeira, Margarita Chli - **Year:** 2020 - **Level:** advanced - **Access:** open

A* search plus B-spline optimisation that favours semantic classes known to be good for visual state estimation, with real-time replanning. Reports better state estimation than a reactive planner and than the Zhang-Scaramuzza perception-aware planner. IROS 2020.

## Key takeaways

- Semantic classes as a proxy for VIO quality
- Later RL version at IROS 2021
