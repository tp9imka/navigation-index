# University of Toronto Foot-Mounted Inertial Navigation Dataset

`res:uoft-foot-mounted-ins-dataset` - dataset - <https://ieee-dataport.org/open-access/university-toronto-foot-mounted-inertial-navigation-dataset>

**By:** Brandon Wagstaff, Valentin Peretroukhin, Jonathan Kelly - **Year:** 2021 - **Level:** intermediate - **Access:** open

Foot-mounted IMU recordings from five subjects over more than 7.6 km with ground-truth positioning, built to evaluate zero-velocity-aided pedestrian INS. Includes non-walking motions such as running, crawling and stair climbing, and mixed walk/run trials. Open access on IEEE DataPort (DOI 10.21227/v1z6-9z84) under a Creative Commons Attribution licence.

## Key takeaways

- Ground truth plus varied gaits makes it a test bed for adaptive zero-velocity detectors
- Companion code is the pyshoe repository
- Crawling and running trials are the relevant ones for dismounted-soldier scenarios
