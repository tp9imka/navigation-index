# Rules for a Remote Student Robotics Competition (IEEE Region 5, 2021)

`res:ieee-r5-2021-tello-drone-rules` - competition - <https://dfc3f084-31d4-418a-8426-e5b4a3d7ef9b.filesusr.com/ugd/2898c3_d846e340f0784f3a91d22469bc16a43c.pdf>

**By:** IEEE Region 5 - **Year:** 2020 - **Level:** intro - **Access:** open

Student contest rules (V4, Nov 2020) for an autonomous DJI Tello on a 3 x 3 m grid. Judges reveal the grid cells and order of four coloured balloons at run start; the drone must reach them in order within 3 minutes. Two divisions separate onboard-only from a standalone off-board computer.

## Key takeaways

- Goal positions given as grid cells only at run start
- Mission Pads banned inside the grid
- Division A no comms, Division B one standalone off-board computer
