# Visual Navigation for Flying Robots (TUM, 2013)

`res:tum-visual-navigation-flying-robots` - lecture-series - <https://cvg.cit.tum.de/teaching/ss2013/visnav2013>

**By:** Jürgen Sturm, Daniel Cremers, TU Munich Computer Vision Group - **Year:** 2013 - **Level:** intermediate - **Access:** open

Award-winning TUM lecture on making quadrotors navigate with cameras: 3D geometry, sensors, state estimation, visual motion estimation, SLAM, dense reconstruction, planning and exploration. Each lecture has slides and a recorded video.

## Key takeaways

- Compact quadrotor-centric syllabus
- Bridges control, estimation and visual SLAM
