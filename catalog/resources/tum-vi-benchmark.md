# TUM VI Benchmark for Visual-Inertial Odometry

`res:tum-vi-benchmark` - dataset - <https://cvg.cit.tum.de/data/datasets/visual-inertial-dataset>

**By:** TU Munich - **Year:** 2018 - **Level:** intermediate - **Access:** open

Handheld stereo camera and IMU sequences indoors and outdoors with photometric calibration; ground truth only at start and end for long sequences.

## Key takeaways

- Sensors: stereo camera, IMU
- Size class: medium
- Good for long-term drift tests
