# Autonomous Navigation for Flying Robots (TUM edX, AUTONAVx)

`res:tum-autonavx` - course - <https://cvg.cit.tum.de/teaching/ss2015/autonavx>

**By:** Jürgen Sturm, Daniel Cremers, TU Munich - **Year:** 2015 - **Level:** intro - **Access:** open

MOOC version of the TUM flying-robots lecture with lecture videos and browser-based Python exercises on quadrotor state estimation, Kalman filtering, control and visual navigation.

## Key takeaways

- Lighter-weight than the full lecture
- Python exercise format is easy to adapt
