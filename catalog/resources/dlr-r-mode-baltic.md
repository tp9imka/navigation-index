# R-Mode Baltic and R-Mode Baltic 2

`res:dlr-r-mode-baltic` - report - <https://www.dlr.de/en/kn/research-transfer/projects/maritime-security/r-mode-baltic-and-r-mode-baltic-2>

**By:** DLR Institute of Communications and Navigation - **Year:** 2021 - **Level:** intro - **Access:** open

DLR project page for R-Mode Baltic, which built a Baltic Sea testbed adding ranging signals to existing maritime radio beacons and AIS base stations as a terrestrial backup to GNSS, continued by R-Mode Baltic 2 and ORMOBASS.

## Key takeaways

- Reuses existing MF beacons and VHF AIS for ranging
- Moving toward IALA standardisation
