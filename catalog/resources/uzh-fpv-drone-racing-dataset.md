# The UZH-FPV Drone Racing Dataset

`res:uzh-fpv-drone-racing-dataset` - dataset - <https://fpv.ifi.uzh.ch/>

**By:** University of Zurich RPG - **Year:** 2019 - **Level:** advanced - **Access:** open

High-speed, aggressive FPV drone flights with camera, event camera and IMU data, with a leaderboard and recurring state estimation competitions.

## Key takeaways

- Sensors: cameras, event camera, IMU
- Size class: medium
- Hard for most VIO pipelines
