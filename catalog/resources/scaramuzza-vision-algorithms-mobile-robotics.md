# Vision Algorithms for Mobile Robotics (UZH/ETH)

`res:scaramuzza-vision-algorithms-mobile-robotics` - course - <https://rpg.ifi.uzh.ch/teaching.html>

**By:** Davide Scaramuzza, Robotics and Perception Group, UZH - **Year:** 2026 - **Level:** intermediate - **Access:** open

Graduate course building a monocular visual odometry pipeline step by step: image formation, calibration, feature detection, two-view geometry, P3P+RANSAC, bundle adjustment, KLT tracking, place recognition, visual-inertial fusion and event cameras. Slides and Matlab/Python exercises with solutions are public; recordings go to the UZH platform.

## Key takeaways

- Exercises culminate in a working mini VO pipeline
- Covers place recognition and VIO fusion
- Python templates available alongside Matlab

**Concepts:** [Visual(-inertial) odometry](../../catalog/concepts/vio.md), [Feature detection and matching](../../catalog/concepts/feature-matching.md), [Sensor calibration](../../catalog/concepts/calibration.md), [Place recognition and loop closure](../../catalog/concepts/place-recognition.md)
