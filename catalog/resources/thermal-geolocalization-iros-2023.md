# Long-range UAV Thermal Geo-localization with Satellite Imagery

`res:thermal-geolocalization-iros-2023` - paper - <https://arxiv.org/abs/2306.02994>

**By:** Jiuhong Xiao, Daniel Tortei, Eloy Roura, Giuseppe Loianno - **Year:** 2023 - **Level:** advanced - **Access:** open

Matches night-time UAV thermal imagery to satellite RGB maps using domain adaptation to cope with scarce paired thermal-satellite data; releases code and a nighttime dataset.

## Key takeaways

- Night visual GPS is possible via thermal-to-RGB matching
- Domain adaptation offsets missing paired data
