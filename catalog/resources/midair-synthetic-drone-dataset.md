# Mid-Air Dataset

`res:midair-synthetic-drone-dataset` - dataset - <https://midair.ulg.ac.be/>

**By:** University of Liege - **Year:** 2019 - **Level:** intermediate - **Access:** open

Synthetic low-altitude quadcopter flights with RGB, depth, normals, semantics and stereo plus navigation sensors, each trajectory recorded under several weather and season conditions.

## Key takeaways

- Sensors (simulated): RGB, depth, IMU, GPS
- Size class: large
- Built on AirSim
