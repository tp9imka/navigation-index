# GTSAM Tutorial: Factor Graphs and GTSAM

`res:gtsam-tutorial-intro` - doc - <https://gtsam.org/tutorials/intro.html>

**By:** Frank Dellaert, Georgia Tech Borg Lab - **Year:** 2020 - **Level:** intermediate - **Access:** open

Hands-on introduction to the GTSAM library: modelling robot odometry, landmark and pose-graph SLAM as factor graphs, solving with Levenberg-Marquardt or iSAM2, and reading marginal covariances, with C++ and Python snippets.

## Key takeaways

- Shortest path to a working pose-graph in Python
- Pattern reusable for GNSS/INS/visual factor fusion
