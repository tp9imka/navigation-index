# ITU-T G.8273.2: Timing characteristics of telecom boundary clocks and telecom time synchronous clocks for use with full timing support from the network

`res:itu-t-g8273-2-tbc-tsc` - standard - <https://www.itu.int/rec/T-REC-G.8273.2>

**By:** ITU-T SG15 - **Year:** 2023 - **Level:** advanced - **Access:** open

Performance limits for telecom boundary clocks (T-BC) and telecom time slave clocks (T-TSC): constant and dynamic time error, noise generation, tolerance and transfer, by clock class. In-force edition 06/2023 with amendments 08/2024 and 11/2025 per the ITU page.

## Key takeaways

- Defines the clock classes (A/B/C/D) whose per-hop time error sums into the G.8271.1 budget
- Gives the vocabulary for reporting a PTP chain: cTE, dTE, max|TE|
- Use it to set honest per-hop error assumptions in a simulation
