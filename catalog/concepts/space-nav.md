# Space and orbital navigation

`concept:space-nav`

Orbit determination, LEO-PNT, spacecraft navigation.

## Repositories (11)

- [Skyfield](../../catalog/repos/skyfielders__python-skyfield.md) - fit: high - Python library for high-accuracy positions of stars, planets and Earth satellites, with proper time scales and reference frames.
- [tetra3](../../catalog/repos/esa__tetra3.md) - fit: high - Fast lost-in-space plate solver for star trackers from ESA: identifies stars in an image and returns attitude using a precomputed pattern database.

- [LOST](../../catalog/repos/uwcubesat__lost.md) - fit: medium - Open-source star tracker (C++) covering centroiding, star identification and attitude estimation, from the UW CubeSat team.
- [SPEED+ baseline](../../catalog/repos/tpark94__speedplusbaseline.md) - fit: medium - PyTorch baselines and domain-bridging methods for spacecraft pose estimation on the SPEED+ dataset used in ESA Kelvins SPEC2021.
- [UT Starlink signal simulator](../../catalog/repos/gitlab.com__radionavlab__public__ut-starlink-signal-simulator.md) - fit: medium - MATLAB utility functions from UT Austin's Radionavigation Lab for simulating Starlink Ku-band downlink signals (OFDM frames, PSS/SSS, Doppler and path-loss histories), with MATLAB live-script playground examples.
- [SPEL Open Star Tracker](../../catalog/repos/spel-uchile__star_tracker.md) - fit: low - Open star tracker software from the University of Chile space lab, flown on SUCHAI nanosatellites.
- [JointLoc](../../catalog/repos/luoxubo__jointloc.md) - fit: low - Real-time visual localization framework for planetary UAVs that jointly uses relative and absolute pose estimation against orbital maps.
- [FederNet](../../catalog/repos/sirbastiano__federnet.md) - fit: low - Terrain relative navigation for planetary landing that detects craters with a Mask R-CNN and matches them to a catalog using projective invariants.
