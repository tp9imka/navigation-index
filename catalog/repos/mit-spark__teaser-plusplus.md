Certifiable, outlier-robust point-cloud registration library with C++, Python and MATLAB bindings.

**Why it matters:** Global registration that tolerates extreme outlier rates, useful for map-to-map alignment and relocalization.

**Hackathon notes:** Needs correspondences (e.g. FPFH) as input; Python bindings make it quick to prototype.
