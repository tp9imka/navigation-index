C++ library (successor to GPSTk) from UT Austin ARL for GNSS data formats, time systems, ephemeris handling and positioning algorithms, with Python bindings.

**Why it matters:** Long-lived, carefully engineered GNSS core library used in US research and monitoring work.

**Hackathon notes:** Build is CMake-heavy; use for robust format and time handling rather than quick demos.
