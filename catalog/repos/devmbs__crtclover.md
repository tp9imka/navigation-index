Drone-side backend of the Clover Rescue project (CopterHack 2022, third place), which the team describes as returning the Clover to the user or takeoff point with one click when radio contact is lost.

**Why it matters:** Lost-link return-home is the same behaviour EW-resilience work needs; this is a small worked example on Clover.

**Hackathon notes:** Pair with DevMBS/CRTClient. Old (2022) and tied to the Clover image.
