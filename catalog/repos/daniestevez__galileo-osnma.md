Rust implementation of Galileo OSNMA that can run on embedded no_std targets, with examples for live receivers.

**Why it matters:** Lightweight, memory-safe OSNMA verifier suitable for embedding in drones or edge devices.

**Hackathon notes:** Cargo build; includes a u-blox-based example. Embedded angle is a differentiator.

**Concepts:** [GNSS positioning](../concepts/gnss.md), [Assured / resilient PNT](../concepts/assured-pnt.md), [Onboard / edge AI perception](../concepts/edge-ai.md)
