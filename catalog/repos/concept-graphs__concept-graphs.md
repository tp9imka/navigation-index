Builds open-vocabulary 3D scene graphs from RGB-D by associating 2D foundation-model detections across views, then lets an LLM plan over the graph.

**Why it matters:** Object-level semantic maps an LLM can reason about, useful for tasking and situational awareness.

**Hackathon notes:** Heavy dependencies (SAM, CLIP, GroundingDINO); start from Replica examples.
