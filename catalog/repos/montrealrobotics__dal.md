Research code for Deep Active Localization: learned perception plus an RL planner that picks actions to localize a robot in a known map, with Gym/Gazebo environments.

**Why it matters:** A ready reference for how learned active localization is set up and benchmarked; useful as a contrast to a model-based maneuver selector.

**Hackathon notes:** License MIT (gh api 2026-11-09). Last push 2020-05-12; PyTorch 1.0 era, expect dependency repair. Indoor ground robot; read for the benchmark design, do not build on it in 48h.
