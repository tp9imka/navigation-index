ROS 1/ROS 2 driver for Livox LiDARs such as Mid-360 and HAP.

**Why it matters:** Mid-360 is a common cheap LiDAR for drones; you need this driver to feed FAST-LIO and friends.

**Hackathon notes:** Build with the Livox SDK2; set the custom message format expected by FAST-LIO.
