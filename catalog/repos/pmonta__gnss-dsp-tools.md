Python code generators, acquisition and tracking for many GNSS signals (GPS, Galileo, GLONASS, BeiDou, NavIC and more) operating on IQ recordings.

**Why it matters:** Broadest signal coverage among lightweight SDR toolkits; quick to test a new recording.

**Hackathon notes:** Run acquire-*.py on an IQ file from any SDR; no build needed.

**Concepts:** [Software-defined GNSS receivers](../concepts/gnss-sdr.md), [GNSS positioning](../concepts/gnss.md)
