Dataset and baseline code for drone-based geo-localization across drone, satellite and ground views of university buildings worldwide.

**Why it matters:** The standard drone-to-satellite retrieval benchmark; most cross-view papers report on it.

**Hackathon notes:** Dataset requires a request form; the synthetic drone views are building-centric, not wide-area terrain.
