Code for the paper 'Assisting UAV Localization via Deep Contextual Image Matching': locates an aerial template inside a larger georeferenced map with a SIFT pipeline and a deep variant built on Neighbourhood Consensus Networks, then reads GPS coordinates with GDAL.

**Why it matters:** A zero-training baseline to compare learned matchers against; mirrors classic DSMAC-style scene correlation in spirit.

**Hackathon notes:** Runs instantly; good as a fallback or ablation baseline in a demo.
