MATLAB implementation of the OpenShoe zero-velocity-aided foot-mounted INS with several zero-velocity detectors (SHOE, acceleration variance and magnitude, angular rate energy).

**Why it matters:** Reference for dismounted soldier / first responder navigation without GNSS.

**Hackathon notes:** Works with any foot-mounted IMU log; sample data included. No updates since 2021.

**Concepts:** [Indoor and pedestrian navigation](../concepts/indoor-pedestrian.md), [Inertial navigation (INS/IMU)](../concepts/ins.md)
