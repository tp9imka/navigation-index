Model and world repository for the new Gazebo, used by PX4 SITL targets such as gz_x500.

**Why it matters:** Shows how PX4 vehicles and sensors are described for gz-sim; the starting point for adding custom sensors to a PX4 airframe.

**Hackathon notes:** Fetched automatically by PX4 SITL. Fork and edit SDF to add cameras or change sensor noise.
