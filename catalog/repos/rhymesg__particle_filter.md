MATLAB particle filtering examples for terrain-referenced navigation, comparing standard, auxiliary, mixture and out-of-sequence measurement particle filters (accompanies an IEEE TAES 2018 paper).

**Why it matters:** Directly addresses the ambiguous-terrain problem that breaks naive TRN.

**Hackathon notes:** Runs in MATLAB with simulated terrain; port the update logic to Python for a DEM demo.
