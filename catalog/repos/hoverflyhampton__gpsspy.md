Python implementation of GPS jamming detection from receiver signal-to-noise ratio, following a published real-time jamming detection method.

**Why it matters:** Simple, explainable C/N0-based jamming detector to start from.

**Hackathon notes:** Small codebase from 2021; adapt to read C/N0 from pyubx2 or Android logs.
