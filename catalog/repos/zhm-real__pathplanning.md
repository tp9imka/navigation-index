Collection of search-based (A*, LPA*, D* Lite, ARA* and others) and sampling-based (RRT, RRT*, Informed RRT*, BIT*, FMT*) planners in Python with animations, in both 2D and 3D folders.

**Why it matters:** MIT-licensed Python with 3D search and 3D RRT folders, so code can be lifted into a hackathon build without a license problem.

**Build notes:** License MIT, last push 2023-02-06 (gh api): static but stable. Search_3D and rrt_3D folders exist; not run here. Educational code, not optimised: fine for a 50x50x10 grid, slow for large 3D maps.
