# Gagarin - TERCOM for UAVs without GNSS

Python TERCOM pipeline from the June 2026 'Полёт вслепую' hackathon, continued into July: correlates radar-altimeter profiles with a DEM using a coarse-to-fine 360-degree search, a hybrid MAD+NCC metric, minima-ratio discrimination, pre-rejection gates and an error-state Kalman filter with dead-reckoning fallback. Adds pre-flight terrain-informativeness analysis along a route, flags false-correlation risk segments, and tabulates expected search time on companion computers (RPi, Jetson, Orange Pi). README (Russian) reports per-region errors honestly, including failures where the azimuth was wrong.

**Why it matters:** Shows the failure modes of altimeter TERCOM in practice (wrong-azimuth peaks, flat terrain) and the engineering answers: quality grading, ambiguity detection and pre-flight route fingerprinting.

**Hackathon notes:** Best starting point if the brief is altimeter + DEM: the NCC/MAD search, quality gates and pre-flight terrain analyzer are separable. Performance table gives realistic onboard budgets. Self-reported errors are 50 m to 1.5 km depending on region, so treat as a baseline, not a result to quote.
