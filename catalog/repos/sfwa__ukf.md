Templated C++ unscented Kalman filter library for state and parameter estimation, including square-root variants, aimed at embedded use.

**Why it matters:** Option for an embedded UKF attitude/navigation filter with compile-time state definitions.

**Hackathon notes:** Heavy template code; worth it only if you specifically need a UKF on a microcontroller-class target.
