Julia blade element momentum (BEM) solver for propellers and turbines, returning thrust, torque and efficiency from blade geometry and airfoil data.

**Why it matters:** A propeller model you can trust when the brief stresses propulsion; it can generate thrust / power maps for an energy-aware planner.

**Build notes:** License MIT Expat (LICENSE.md read; GitHub shows NOASSERTION). Last push 2026-09-24. Julia toolchain is extra setup; for a Python team, AeroSandbox's propeller module or the UIUC propeller data is quicker.
