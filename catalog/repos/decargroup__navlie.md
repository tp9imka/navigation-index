Python state estimation package on Lie groups (McGill DECAR): EKF, iterated EKF, sigma-point filters, batch estimation, and IMU kinematics models.

**Why it matters:** Fastest way to prototype on-manifold INS filters in Python.

**Hackathon notes:** pip install; has IMU and GNSS-like examples.
