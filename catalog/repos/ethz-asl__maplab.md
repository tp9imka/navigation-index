Modular multi-session, multi-modal mapping framework with map merging, optimization and localization against saved maps.

**Why it matters:** Build a map once, then localize repeatedly against it; supports multi-robot and multi-session merges.

**Hackathon notes:** Large ROS 1 codebase; only worth it if you need persistent map management.
