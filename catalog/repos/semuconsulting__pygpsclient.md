Cross-platform Python GUI GNSS client that displays and configures receivers over NMEA, UBX, RTCM3 and other protocols, with built-in NTRIP and SPARTN clients.

**Why it matters:** Fast visual tool for checking receiver state, satellite C/N0 and corrections during field tests.

**Hackathon notes:** pip install pygpsclient. Good bench tool to watch C/N0 drop during a jamming test in a shielded setup.

**Concepts:** [GNSS positioning](../concepts/gnss.md), [RTK / PPP precise positioning](../concepts/gnss-rtk-ppp.md)
