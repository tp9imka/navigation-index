Runtime monitor framework for Mission-time Linear Temporal Logic. A compiler (C2PO) turns specs into a compact binary that a small C or Rust engine evaluates on streaming sensor data, sized for constrained flight hardware.

**Why it matters:** Temporal properties such as 'innovation above gate for more than 2 s implies fallback' are exactly what a nav health monitor checks. R2U2 evaluates them on a microcontroller budget.

**Build notes:** Python 3.9+ for the spec compiler, a C99 compiler for the engine. Replay a ulog or bag through it offline to show which seconds of a flight the monitor would have flagged. Small project (tens of stars), so expect thin docs.
