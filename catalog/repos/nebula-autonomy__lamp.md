Team CoSTAR's large-scale multi-robot lidar SLAM back end with robust loop closure, from the NASA JPL-led SubT entry.

**Why it matters:** Open component of the NeBula stack that won the SubT Urban circuit; shows multi-robot GNSS-denied mapping done at challenge scale.

**Hackathon notes:** ROS1 and dormant since 2023; run on the NeBula multi-robot dataset rather than live hardware.
