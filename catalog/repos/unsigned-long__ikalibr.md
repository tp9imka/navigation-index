Continuous-time, targetless multi-sensor calibration framework (IMU, cameras, LiDAR, radar, RGB-D, event cameras) estimating extrinsics and time offsets (IEEE T-RO 2025).

**Why it matters:** Calibrate a full heterogeneous rig, including radar, in one tool.

**Hackathon notes:** ROS-based with many dependencies; budget setup time.

**Concepts:** [Sensor calibration](../concepts/calibration.md), [Sensor fusion and state estimation](../concepts/sensor-fusion.md), [ROS / ROS 2 robotics middleware](../concepts/ros.md)
