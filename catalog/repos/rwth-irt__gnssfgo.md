Online, time-centric factor graph optimization for GNSS and multi-sensor vehicle localization in ROS 2, with a Docker image and launch files for its Aachen data.

**Why it matters:** A working ROS 2 example of an asynchronous multi-sensor factor graph where sensors arrive at different rates, the architecture behind plug-and-play fusion.

**Build notes:** BSD-3-Clause. Archived since 2024; README says maintenance moved to the fork hz658832/gnssFGO. Docker pull is the fastest way to see it run.
