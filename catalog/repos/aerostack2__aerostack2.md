ROS 2 framework for autonomous multi-aerial-robot systems: platform abstraction (PX4, DJI, Crazyflie, Gazebo), behaviors, mission scripting in Python and BT, and multi-drone coordination.

**Why it matters:** One of the few ROS 2 native UAV mission frameworks that spans simulation to several real autopilots, good for multi-drone mission demos.

**Hackathon notes:** Binary packages for Humble; Python mission API lets you script takeoff/goto/land for several drones quickly.

**Concepts:** [ROS / ROS 2 robotics middleware](../concepts/ros.md), [Swarms and multi-agent navigation](../concepts/multi-agent.md), [Mission planning and routing](../concepts/mission-planning.md), [Autopilots and flight control](../concepts/autopilot.md)
