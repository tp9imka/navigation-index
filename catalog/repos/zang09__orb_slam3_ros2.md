ROS 2 wrapper package that exposes ORB-SLAM3 as nodes for monocular, stereo and RGB-D input.

**Why it matters:** Shortest path to running ORB-SLAM3 inside a ROS 2 robot stack.

**Hackathon notes:** Needs a working ORB-SLAM3 build first; check the README for the ROS 2 distro it targets before choosing your Docker base image.
