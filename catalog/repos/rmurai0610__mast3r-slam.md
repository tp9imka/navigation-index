Real-time dense monocular SLAM built on the MASt3R two-view 3D reconstruction prior, needing no fixed camera model (CVPR 2025).

**Why it matters:** Works with uncalibrated cameras, useful for opportunistic imagery from unknown cameras.

**Hackathon notes:** Requires a capable NVIDIA GPU and model checkpoint downloads. Great demo value on handheld video.
