Open-source flight dynamics model library for fixed-wing and other aircraft, used by FlightGear and as an ArduPilot SITL backend.

**Why it matters:** Credible fixed-wing dynamics for testing navigation filters on aircraft profiles rather than quadcopters.

**Hackathon notes:** Python bindings via pip. Combine with ArduPilot SITL for an autopilot loop.
