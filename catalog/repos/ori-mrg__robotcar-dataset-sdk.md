**Why it matters:** Long-term, all-condition driving data is a staple for localization and place recognition research.

**Hackathon notes:** Inactive since 2022; Python and MATLAB helpers still work. The dataset itself is CC BY-NC-SA 4.0, for non-commercial academic use only.
