Sample app and docs entry for DJI MSDK V5, the Android SDK for current DJI consumer and enterprise aircraft, including the virtual stick API.

**Why it matters:** If the platform is a DJI consumer drone, virtual stick through MSDK is the only way to send setpoints from your own code.

**Hackathon notes:** Android-only toolchain, DJI app key registration, and aircraft/controller compatibility limits (Mini 4 Pro needs RC-N2 per press). Advanced virtual stick wants 5-25 Hz setpoints. Expect hours before first autonomous move. License NOASSERTION.
