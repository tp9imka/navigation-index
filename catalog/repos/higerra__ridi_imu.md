Code for RIDI, which regresses velocity from smartphone IMU data with learned models to reduce inertial drift for pedestrian navigation.

**Why it matters:** Ancestor of RoNIN/TLIO-style learned inertial odometry.

**Hackathon notes:** Old dependencies; prefer RoNIN for new work.
