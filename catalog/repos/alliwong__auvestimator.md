Work-in-progress EKF that fuses DVL, IMU and barometer data for AUV state estimation, with a ROS wrapper.

**Why it matters:** Small, readable DVL-aided INS example to start a GNSS-free underwater nav filter from.

**Hackathon notes:** Dormant since 2021; treat as a starting template, not a dependency.
