Minimal C implementation of the DroneCAN protocol used for GNSS, compass, airspeed and other peripherals on CAN.

**Why it matters:** Needed to build custom CAN sensors (e.g. an alternative nav sensor) that ArduPilot/PX4 can consume.

**Hackathon notes:** Use with dronecan/DSDL; mostly for hardware teams.
