Russian graduate thesis code: 'Development of a UAV inertial navigation module using auxiliary navigation data'. C++ client for INS/GNSS fusion, a C# flight simulator with sensor emulation, a Node.js telemetry server and a Vue web UI.

**Why it matters:** Small, self-contained INS + aiding simulator with a visual front-end; good for teaching drift and aiding.

**Hackathon notes:** Mixed C++/C#/Node stack; setup cost moderate. Treat as reference, not a library.
