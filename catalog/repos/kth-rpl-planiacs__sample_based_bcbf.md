Python code for the CDC 2025 sample-based belief CBF paper: simulation environments for tracking and collision avoidance and the belief-CBF policies.

**Why it matters:** The only belief-CBF code found from the Vahs group; useful to check a re-implementation of the 2023 Gaussian BCBF baseline.

**Build notes:** License MIT per gh api, last push 2025-07-21. README says to use a mamba environment from environment.yml; when time is short use a sample-local venv instead. Not run. Implements the sample-based variant, not the 2023 EKF version.
