Python implementation of the Consensus-Based Bundle Algorithm for decentralized multi-agent task allocation with plotting examples.

**Why it matters:** CBBA is the classic decentralized auction for assigning tasks to UAV teams; this is an easy-to-read starting point.

**Hackathon notes:** numpy + matplotlib only; wrap in a ROS 2 node or call from a mission script to assign search cells to drones.
