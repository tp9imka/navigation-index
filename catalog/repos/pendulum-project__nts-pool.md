Server side for a pool of NTS time servers: a key-exchange front end that hands clients to member servers while keeping authentication end to end.

**Why it matters:** Authenticated public time at pool scale is a prerequisite for using network time as an anti-spoofing cross-check.

**Hackathon notes:** Background reading for the authenticated-time story; not needed to build a demo.
