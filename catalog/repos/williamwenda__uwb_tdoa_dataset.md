Dataset and scripts for UWB time-difference-of-arrival measurements from Bitcraze's Loco Positioning System, collected by University of Toronto.

**Why it matters:** Real UWB data for testing ranging-based estimators without hardware.

**Hackathon notes:** Download and run the provided EKF example as a baseline. Unmaintained since 2021; the data itself is static and still usable.
