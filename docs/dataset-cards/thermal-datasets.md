# Thermal navigation datasets (Boson-nighttime, CART, MS2)

<!-- about: repo:arplaboratory/sthn, repo:arplaboratory/satellite-thermal-geo-localization, res:thermal-geolocalization-iros-2023, res:sthn-thermal-homography-2024, res:uasthn-uncertainty-thermal-2025 -->

Three open thermal datasets that matter for GNSS-denied navigation at night. Only the
Boson-nighttime dataset is reachable from index entries (via STHN / STGL); CART and MS2 are
not indexed.

| Dataset | Platform | Sensors | GT | Size | License |
|---|---|---|---|---|---|
| Boson-nighttime (NYU ARPL) | UAV, night flights | Thermal (FLIR Boson, per name) + paired satellite RGB (Bing) | Satellite-aligned thermal crops (alignment method/accuracy not checked) | v1 74.2 GB, v3 130.9 GB + extended queries 84.7 GB (HF API) | HF gate: non-commercial research only; HF tag MIT |
| CART, Caltech Aerial RGB-Thermal (ECCV 2024) | Aerial robots over natural terrain, ArduPilot logs included | RGB, LWIR thermal, GPS, IMU, ROS1 bags | GPS/IMU; semantic labels for 10 classes on a subset | Labeled zips 8.4 GB; raw bags about 677 GB listed (Caltech page) | CC BY-NC 4.0 |
| MS2, Multi-Spectral Stereo (KAIST, CVPR 2023) | Car | Stereo RGB, stereo NIR, stereo thermal, lidar, GPS/IMU | Odometry and projected lidar depth | Not verified (form on Google Site) | Not checked |

## Boson-nighttime (STGL / STHN)

- What: night UAV thermal imagery paired with satellite RGB maps, for thermal-to-satellite
  geo-localization (IROS 2023) and homography estimation (STHN, RA-L 2024; UASTHN 2025).
  v3 adds unpaired satellite imagery and thermal images generated by the authors' TGM model.
- Ground truth: paired thermal/satellite crops in HDF5 (`train_database.h5`,
  `train_queries.h5`, ...). Flight altitude, location and camera not stated on the pages
  checked; the arXiv abstract only says "real data collected onboard a UAV".
- Gated on Hugging Face: you fill in name, affiliation, intended use and accept
  non-commercial terms; approval mode "auto" (API, 2026-11-06).

```bash
hf auth login            # needs an HF account that has accepted the gate
hf download xjh19972/boson-nighttime --repo-type dataset \
  --include "satellite-thermal-dataset-v1/*" --local-dir boson   # 74 GB, STGL layout
cat boson/satellite-thermal-dataset-v1/thermal_dataset.tar.gz.parta* | tar xz
# STHN uses satellite-thermal-dataset-v3 (README says 122 GB; HF lists 130.9 GB + 84.7 GB extended)
```

- No small subset. For a demo without the download, the STHN repo's `STHN_demo.py` pulls the
  model from Hugging Face and runs on bundled example pairs; the dataset repo also has three
  `examples/*.jpg` pairs.

## CART (Caltech Aerial RGB-Thermal)

- Flights at 11 site/date folders (beach, rivers, lakes, desert, forest, coast) 2021-2023;
  synchronized RGB, thermal, GPS, IMU; time-of-day splits (sunrise, day, night) for thermal
  inversion studies; benchmarks for thermal segmentation, RGB-T translation and VIO.
- Labeled data downloads directly; raw bags sit on an S3-compatible OSN bucket.

```bash
curl -L -o labeled_thermal_singles.zip \
  "https://data.caltech.edu/records/cks6g-ps927/files/labeled_thermal_singles.zip?download=1"
# raw bags: https://sdsc.osn.xsede.org/ini210004tommorrell/cks6g-ps927/data/<date_Site>/<ts>/<ts>.bag
git clone https://github.com/aerorobotics/caltech-aerial-rgbt-dataset  # rosbag/ardupilot extractors, rectifier
```

Smallest raw sequence: Beach 2021-07-21, 2 bags, about 5.3 GB (Caltech file list).

## MS2

- Driving dataset: synchronized stereo RGB / NIR / thermal + lidar + GPS/IMU, with projected
  depth and odometry in every camera frame. Download via the form at
  https://sites.google.com/view/multi-spectral-stereo-dataset ; loader and `demo.py` in
  https://github.com/UkcheolShin/MS2-MultiSpectralStereoDataset .

## Loading and tooling

- [STHN](../../catalog/repos/arplaboratory__sthn.md) and
  [satellite-thermal-geo-localization](../../catalog/repos/arplaboratory__satellite-thermal-geo-localization.md):
  HDF5 loaders and pretrained models for thermal-to-satellite matching.
- Thermal-inertial odometry for CART bags: [ROVTIO](../../catalog/repos/ntnu-arl__rovtio.md),
  [ETIO](../../catalog/repos/hitsz-nrsl__etio.md); score with [evo](../../catalog/repos/michaelgrupp__evo.md)
  against the GPS track.

## Hackathon fit

- Idea 18 / 20 at night: "visual GPS still works after dark" is a strong demo; run STHN's
  demo on example pairs and show the error.
- Idea 10 (VIO GPS-free flight): CART bags give a thermal-inertial odometry baseline in
  terrain without features for RGB.

## Pitfalls

- Boson-nighttime is huge and gated; there is no subset under 74 GB. Use the demo pairs.
- CART record shows 22.1 TB total volume vs about 677 GB listed; the file list may be
  incomplete (per the Caltech page).
- CART position "preferred data" and sync docs are "coming soon" in its README.
- All three are non-commercial or unchecked licenses.
