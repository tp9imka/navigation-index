# Evidence matrix

Every measured number in the hub's samples, by capability, with the kind of input it was
measured on. This is the page to cite from in a pitch. Numbers are copied from each sample's
README (snapshot 2026-11-06, refreshed after review round 2); the link in the first column
goes to the README section that holds the full table. Nothing here was re-run for this page
except the dismounted filter table (section 8), which reproduced on the author's data.
When a sample has a newer result that supersedes an older one (altpnt-integrity v2, the
reworked interference scorer), the older number is labelled as such; quote the newer one.

**Input column.** `real` = recorded public data (named). `SITL` = real autopilot firmware in
simulation, simulated sensors. `synthetic` = simulated vehicle and sensors, sometimes over real
terrain, maps or traffic (named). A synthetic or SITL number shows that a method works under the
stated model; it is not a field result. Say which kind it is when you quote it.

**Runs column.** How many seeds, flights or trials stand behind the number. One run is an
example, not a statistic.

Sample index with status and first command: [samples/README.md](../samples/README.md).
Which statement each capability answers: [problem-statement-decoder.md](problem-statement-decoder.md).

## 3. Integrity metrics: protection level, misleading information

MI = position error above the protection level while the PL is below the alert limit (AL);
HMI = error above the AL while the PL says it is fine.

altpnt-integrity has two results. **Quote v2.** v1's "0 MI at 41.7 % availability" holds only
under v1's own assumed noise; the sample's
[v2 section 4](../samples/altpnt-integrity/README.md#4-what-changed-vs-v1-honestly) shows it does
not survive error models measured on real runs (v1 assumed a 0.23 deg heading error; OpenVINS
measured 3.58 deg over the whole run, up to 5.23 deg per window). The calibration lesson: an
integrity number is only as good as the error model under it, and an overbound measured in one
condition does not transfer to another.
MI* = MI + HMI + unavailable-and-MI.
