# Card vs sample cross-check (2026-11-06)

Integration cards were written from READMEs and source. Samples ran the code. This pass copies what the samples measured back into the cards as a `## Verified in this hub` section (inserted before `## Alternatives`), and corrects card statements the samples contradict. Every bullet links the sample README that holds the commands and raw output. Nothing here was re-run for this report: the facts come from the sample READMEs as committed.

Method: read all 32 `samples/*/README.md`, listed the findings about an indexed repo (version pins, API renames, bugs, licence traps, platform quirks, measured performance), and matched them to existing cards. No new cards.
