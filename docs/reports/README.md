# Reports: hand-written reviews, audits and fact checks

Use this page when you want to know what a past review found, how far to trust the records, or
which review is current. Every report here is a dated snapshot: read its date and commit before
you act on a finding, and check the current file it names.

The top-level `reports/` folder is different: `reports/quality.md` there is generated by
`tools/build.py`.
